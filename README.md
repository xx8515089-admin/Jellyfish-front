# Reelmax 前端功能文档

Reelmax 是面向 AI 短剧、分镜、资产生成和视频成片流程的前端工作台。本仓库为前端项目 `Jellyfish-front`，主要负责登录鉴权、项目工作台、自由画布、资产管理、提示词模板、文件管理、Agent、模型供应商、音色库、系统权限等页面能力。

新用户请阅读 [自由画布与 3D 导演台零基础用户手册](docs/canvas-director-beginner-manual.md) · [English](docs/canvas-director-beginner-manual.en.md)，按步骤完成图片生成、图生视频、批量分镜、导演台运镜、参考应用和保存。自由画布顶部与 3D 导演台的“用户手册”入口使用同一份内容。

## 开发启动与检查

在当前前端目录执行，包管理器版本由 `package.json` 的 `packageManager` 指定为 `pnpm@9.15.9`。

```sh
pnpm install
pnpm run typecheck
pnpm run build
```

后端地址在 `.env.local` 中配置 `VITE_BACKEND_URL`；部署时可通过 `public/env.js` 中的 `window.__ENV.BACKEND_URL` 覆盖。未配置时使用同源地址，具体解析逻辑见 `src/config/api.ts`。

服务和端口由开发者手动管理。需要启动前端时运行 `pnpm run dev`；默认配置端口为 `7788`，实际以终端输出为准。不要重复启动已运行的服务。生产构建输出到 `dist/`；需要本地预览构建结果时手动运行 `pnpm run preview`。

### 更新接口客户端

全量同步前需明确配置有效的 `OPENAPI_URL` 或 `VITE_OPENAPI_URL`。脚本不会根据业务后端地址猜测文档地址。确认规范覆盖当前业务后执行：

```sh
pnpm run openapi:update
```

本地契约位于 `docs/contracts/`，生成代码主要位于 `src/services/generated/`。素材导入可使用 `pnpm run openapi:update -- --contract=asset-import` 单独更新；效能总览使用 `pnpm run openapi:efficiency`。各模块的额外生成脚本见 `scripts/`，同步前先阅读对应接入说明。

## 功能总览

- 项目制创作：从剧本导入、项目创建、章节拆分、分镜提取、镜头准备、关键帧生成到视频生成和后期剪辑。
- 资产体系：管理演员、角色、场景、道具、服装，并支持与项目、章节、分镜建立关联。
- 自由画布：提供独立画布工作区，支持云端列表、修订保存、任务恢复、素材关联、批量生成和中英文同步，并兼容旧本地画布。
- 任务中心：全局轮询近 24 小时任务，展示运行中、已完成、失败、取消等状态，并支持按当前页面、任务类型、任务 ID 筛选。
- 系统配置：支持用户、角色、菜单、音色库、模型供应商、模型能力和提示词模板等后台配置。
- 国际化：主应用和自由画布支持简体中文、英文统一切换。

## 最近更新（2026-09-21）

- 菜单与国际化：菜单缓存按账号、语言隔离，切换语言重新加载服务端菜单；画布、导演台及业务页面补齐中英文文案。
- 自由画布：完善受理状态识别、原请求恢复、跨标签页操作锁、保存冲突保护、素材容错与限流退避；增加媒体分析转分镜和管理员任务核查入口。
- 3D 导演台：按素材包隔离模型依赖，校验路径、大小及内容哈希；新增发布回执恢复，并优化按需渲染、相机同步和姿态采样。
- 项目工作流：八类操作持久化原始提交，支持操作记录恢复；配音冻结输入快照，视频按服务端状态轮询，导出使用预检快照并校验下载内容。
- 片段批量视频：支持候选选择、统一参数、逐段时长、预算预检、批次历史、异常恢复和失败项重试。
- 素材导入：接入文本与图片批次导入、动态限额、预览确认、逐项错误、上传复用和限流处理。
- 效能总览：使用服务端统计快照展示积分、耗时和生成次数，支持模型消费分布、项目成员排行、明细钻取及 CSV 导出。
- 列表与文档：项目和画布列表支持最新媒体封面；画布与导演台统一使用中英文零基础手册。

## 全局能力

### 登录与权限

- 路由 `/login` 提供账号密码登录。
- 登录成功后保存后端签发的 bearer session、用户信息和后端返回的菜单快照。
- 页面入口由后端菜单树驱动，侧边栏只展示启用状态且非按钮类型的菜单。
- 未登录访问业务页面时会进入鉴权保护流程。
- 管理员用户展示 API 额度不限；普通用户展示已用额度、总额度和剩余额度。

### 主布局

- 左侧侧边栏支持展开、收起，菜单按后端返回的层级和排序展示。
- 顶部面包屑会根据当前路由生成，并对项目、章节、分镜等子页面做路径映射。
- 进入具体项目后，侧边栏品牌区会展示当前项目名称和项目说明。
- 顶部语言选择器支持 `zh-CN` 和 `en-US`，切换后会同步 i18n、localStorage 和 HTML `lang` 属性。
- 菜单缓存按账号和语言隔离；切换时重新获取服务端菜单，旧账号或旧语言的迟到响应不会替换当前菜单。

### 工作流操作恢复

- 对配音、独立图生视频、资产图、造型图、资产去油、创建分集、提取资产及重试提取这八类操作，在发送前持久化请求标识、账号、语言和原始参数。
- 存在相关记录时显示“操作记录”，支持查询原回执和按原参数恢复；网络超时或受理状态未知时保留记录，阻止直接新建同对象请求。
- 操作记录区分首次响应和当前业务详情，切换账号或页面后不把旧结果写入新上下文。不同任务族继续使用各自的生成与恢复协议。

### 任务中心

- 主布局内置任务运行时 Provider，每 4 秒拉取一次近 24 小时任务。
- 支持全局任务浮窗，记忆打开状态和悬浮按钮位置。
- 可按当前页面相关任务、全部任务、运行中任务、已结束任务切换范围。
- 支持任务类型筛选、任务 ID 搜索、直接查询任务结果、展示进度、耗时和失败摘要。
- 对支持取消的任务提供取消入口。

### 悬浮 AI 助手

- 全局挂载悬浮 AI 助手，登录页和自由画布编辑页不展示。
- 助手图标可拖拽，位置会保存到 localStorage。
- 支持打开聊天面板、最小化、关闭、输入消息、复制回复和快捷建议。
- 当前回复逻辑为前端本地占位回复，后续可接入真实 AI 对话接口。

## 菜单功能

### 项目列表

路由：`/projects`、`/projects/create`、`/projects/:projectId`

项目列表是 Reelmax 的主创作入口，用于查看、搜索、创建、重命名和删除项目。

- 展示“我的项目”卡片列表，支持按作品名称搜索。
- 项目卡片展示封面、解析状态、字数、集数、默认视频比例、创建人和创建时间。
- 项目和画布卡片支持服务端返回的最新媒体封面，具体来源与兼容行为见各自的列表封面接入文档。
- 卡片操作支持进入项目、重命名、删除。
- 快捷入口支持跳转到提示词模板和资产中心。
- 创建入口进入项目创建流程。
- 卡片更多菜单、信息浮层和删除确认弹窗已按当前暗色项目视觉统一优化。
- 创建入口使用更明确的视觉图标，在项目列表和自由画布列表中保持一致。

#### 项目创建

路由：`/projects/create`

- 支持粘贴剧本原文或导入 `.txt`、`.md`、`.doc`、`.docx` 文件。
- 剧本导入后调用解析接口，回填剧本内容、导入 ID 和剧集章节信息。
- 支持确认项目基础信息、视频比例、画面风格、影调风格。
- 风格选项从后端加载，包含“无风格”和在线风格封面预览。
- 支持自定义风格封面裁剪与上传。
- 自定义画面风格和自定义影调风格卡片分别使用独立预览图，避免空白或纯色预览难以识别。
- 创建流程会保存本地草稿，避免刷新或离开页面丢失进度。
- 支持按剧集继续追加导入章节内容。

#### 章节分镜列表

路由：`/projects/:projectId/chapters/:chapterId/shots`

- 展示当前章节分镜表格，支持按序号、标题、剧本摘录搜索。
- 支持按全部、待确认、生成中、已就绪筛选。
- 支持一键 AI 提取分镜、取消分镜提取任务。
- 已有分镜时不允许重复提取，需先清空或删除已有分镜。
- 支持手动创建分镜、编辑分镜、删除单条分镜和批量删除。
- 支持导入分镜表，提供 CSV 模板下载、CSV/TSV 上传、粘贴表格文本、预览导入和行级错误提示。
- 导入分镜仍写入原生 shots、shot details 和 shot links，后续继续走镜头准备、关键帧和视频生成流程。

#### 分镜工作室

路由：`/projects/:projectId/chapters/:chapterId/studio`

- 面向镜头级生成流程，聚合分镜列表、镜头详情、资产关联、提示词、关键帧和视频结果。
- 支持按待确认、生成中、已就绪、隐藏、问题等状态查看镜头。
- 支持首帧、关键帧、尾帧管理，以及采用、废弃等帧图标签。
- 支持生成或编辑首帧、关键帧、尾帧提示词，并根据参考图顺序派生最终提示词。
- 支持选择项目资产作为提示词参考，包括演员、场景、道具、服装。
- 支持创建关键帧图片生成任务，区分标准和高质量分辨率配置。
- 支持视频生成准备度检查、批量检查、视频参考模式和视频结果预览。
- 支持维护面板、诊断面板和批量操作工具栏。

#### 片段编辑、配音与批量视频

- 项目工作流第四步“片段编辑”提供“批量生成”入口，加载可生成片段及不可选原因；支持选择可用项、无成功版本项，服务端数量上限内最多 50 项。
- 统一设置视频模型、分辨率、画幅、音频、视觉及情绪风格，支持自动时长、统一覆盖或逐段补填，并携带当前编辑稿。
- 参数变化后重新预检，展示逐项问题及费用；预算确认后冻结提交参数，超时可找回原请求，历史支持分页和失败项重试。
- 参考素材保存期间阻止批次提交，分集或账号切换后忽略旧响应。生成轮询遵守服务端 `shouldPoll`，产物操作要求 `outputReady=true`。
- 配音生成提交完整输入快照，包括角色、音色、语言、台词、情绪、音量和语速；历史展示对应任务的原始输入。
- 分镜导出使用预检快照令牌，检查响应是否为有效 ZIP；取消、失败或账号变化时停止下载并保留选择。
- 接入细节见 [批量视频](docs/storyboard-video-batch-integration.md) 和 [工作流可靠性](docs/workflow-handoff-20260921-integration.md)。

#### 3D 导演台

路由：`/director-desk`、`/director-desk/workspace/:deskId`、`/projects/:projectId/chapters/:chapterId/director-stage`

- 提供独立导演台首页，可创建和打开本地导演台工作区。
- 支持云工程载入、草稿保存、正式发布和发布回执查询；未确认发布保留原版本与请求标识，支持原样重试并保护后续编辑。
- 以懒加载 React 运行时集成 3D Director Desk，并通过独立样式作用域隔离编辑器样式。
- 支持角色、道具、场景预设和本地模型导入，用于快速搭建 3D 调度场景。
- 模型与依赖按素材包管理，同名文件按包隔离；恢复时校验服务端包信息、文件路径、大小和 SHA-256，依赖缺失时保留错误及重新绑定提示。
- 支持摄影机、构图画幅、视口灵敏度、运镜预设和路线编辑。
- 支持掌镜预览、路线预览、干净截图、参考视频导出和项目 JSON 导入导出。
- 支持从片段进入导演台、生成参考图和应用结果，保留来源与修订关联；发布或上传期间的新编辑会阻止旧快照覆盖。
- 视口使用按需渲染、交互分辨率调整、相机同步和姿态采样优化，减少静止场景及播放过程的重复计算。
- 从项目章节进入时可作为分镜导演台使用，保留原 `/projects/:projectId/chapters/:chapterId/director-stage` 入口。
- 操作文档见 [零基础用户手册](docs/canvas-director-beginner-manual.md) 第 7～11 节；云工程实现参见 [导演台云工程接入](docs/director-desk-cloud-integration.md)。

#### 后期剪辑

路由：`/projects/:projectId/editor`

- 从项目文件中加载视频素材并转换为轻量时间线片段。
- 展示素材库、视频轨道、音频轨道。
- 提供剪切、添加效果、预览和导出成片按钮。
- 当前为轻量剪辑界面，核心拖拽剪辑和真实导出能力仍需后续完善。

### 自由画布

路由：`/canvases`、`/canvas/:canvasId`

自由画布用于独立创意工作区，通过画布后端保存工程、素材和任务；旧本地画布保留兼容入口。

- 画布列表展示“我的画布”，支持搜索画布名称。
- 支持新建画布，默认名称按当前语言显示为“未命名画布”或 “Untitled canvas”。
- 支持画布重命名和删除。
- 云端画布列表、新建、重命名和删除通过画布接口完成；localStorage 注册表用于兼容旧本地画布。
- 每个画布使用独立编辑器缓存，删除时清理对应 localStorage 和 IndexedDB 数据；按账号保存的请求恢复记录继续保留。
- 进入画布后显示顶部栏：返回画布列表、画布名称、自动保存状态。
- 画布编辑器懒加载内置 `TapnowStudio`。
- 主应用语言切换会同步到画布内部；画布内切换语言也会同步回当前项目语言。
- 画布运行区使用隔离样式作用域，避免第三方画布样式污染主应用。
- 画布能力包含图片输入、文字节点、小说输入、角色场景提取、视频输入、关键帧整理、视频拆解与提示词反推、智能分镜表、AI 绘图、AI 视频、图像对比、预览窗口和保存到本地等节点入口。
- 画布工具栏包含性能模式、下载、暗色模式、中英文切换、撤销重做、清空和 API 设置等入口。
- 连接线渲染已拆分为独立 `ConnectionLayer`，统一处理普通连接、图像对比多输入、Midjourney `oref/sref` 输入点和视频起止帧输入点。
- 节点渲染已增加 `CanvasNodeRenderBoundary`，在拖拽、缩放、框选、连线等交互过程中减少无关节点重渲染。
- 节点坐标更新通过 `useRafNodeUpdates` 合并到 requestAnimationFrame，批量移动大量节点时会使用索引映射提升更新效率。
- 节点拖拽过程中优先使用 DOM transform 投影和连接线同步投影，拖拽结束后再提交真实坐标，提升拖拽流畅度。
- 云端保存支持修订校验、草稿恢复、素材上传复用和不确定请求回执找回；切换画布时隔离工程及媒体状态。
- 图片、视频和分镜任务支持保存后报价、确认预留积分、批量提交、历史筛选，以及按服务端动作取消、重试或补拉。
- 文本任务包含描述增强、过滤、角色场景提取、分镜拆分和提示词汇总；结果经确认后应用，并检查输入变化。
- 支持关联角色、场景和道具；图片经服务端初筛后入库，保留真实库条目及来源信息。
- 云端聊天支持会话、附件和任务恢复；聊天与媒体分析按后端明确的实际用量计费协议执行，展示真实结算状态和未知费用，不将待核算金额视为零。
- 媒体分析支持关键帧反推、视频导演拆解及音轨转写，结果经确认后应用；支持转为分镜并保留帧来源，依赖工作流支持后端已开放的文本和分析操作。
- 提交前保存原请求，按服务端受理状态处理恢复；跨标签页操作锁和账号隔离减少重复提交，迟到回执不会直接覆盖新编辑。
- 素材读取失败显示局部提示并允许重试，保留原绑定；下架模型的旧绑定仍可保存，新生成须选择可用模型。
- 按服务端重试间隔与限流响应退避，后台降低轮询频率；暂停媒体写入时保留历史读取及文字编辑。
- 管理员且后端核查能力开放时可查看待核查任务、登记证据和恢复核查请求；证据登记不等于前端直接修改任务或余额。
- 支持节点自动排列；视口更新、连线计算和媒体预览使用缓存减少重复工作，统一弹窗隔离后台画布快捷键。
- 操作文档见 [零基础用户手册](docs/canvas-director-beginner-manual.md) 第 3～6 节；开发时结合 [V2 基础接入](docs/free-canvas-cloud-integration-v2.md)、[V3 增量接入](docs/free-canvas-cloud-integration-v3.md) 和 [最新契约接入记录](docs/canvas-handoff-20260921-integration.md) 阅读；节点维护参见 [样式规范](docs/free-canvas-node-style.md)。

### 资产管理

路由：`/assets`

资产管理是全局资产库入口，按资产类型分 Tab 管理。

- 顶部提供批量导入资产清单、批量导入本地资产图片、批量生成资产图和资产关联项目入口。
- Tab 包含演员、场景、道具、服装。
- 支持通过 URL 参数 `tab=actor|scene|prop|costume` 定位具体资产类型。
- 支持进入独立编辑页：
  - 演员：`/assets/actors/:actorImageId/edit`
  - 场景：`/assets/scenes/:sceneId/edit`
  - 道具：`/assets/props/:propId/edit`
  - 服装：`/assets/costumes/:costumeId/edit`
- 项目工作台中的演员、角色、场景、道具、服装 Tab 会复用资产库数据并建立项目关联。
- 图片展示统一通过文件下载地址或后端返回缩略图地址解析。
- 文本清单及本地图片可按批次导入，动态读取模板与大小限额，先预览再提交，展示逐项错误及分页结果。
- 上传按内容哈希复用同一条目的请求标识；提交冻结预览令牌和修订，超时保留原请求，失败项仅在服务端允许时重试。
- 限流按 `Retry-After` 等待；成功后刷新相应资产列表，保留无封面占位和自定义标签。详见 [素材批量导入接入记录](docs/asset-import-20260921-integration.md)。
- 资产图片支持按选中版本进行版权审查，展示风险等级、依据、画面位置和修改建议，支持失败重试。

### 提示词模板

路由：`/prompts`

提示词模板用于管理系统级 prompt 模板，当前接入系统提示词接口。

- 支持从 `/api/v1/system/promptTemplates/findAll` 加载全部模板。
- 支持按模板名称、类别、预览文案或内容搜索。
- 表格展示名称、类别编码、预览、系统模板标记、默认模板标记和操作。
- 右侧详情面板展示模板基础信息、模板内容和变量信息。
- 支持新增、编辑、删除模板。
- 模板表单包含类别、名称、预览文案、模板内容、系统模板开关和默认提示词开关。
- 新增接口：`/api/v1/system/promptTemplates/create`。
- 更新接口：`/api/v1/system/promptTemplates/update`。
- 删除接口：`/api/v1/system/promptTemplates/delete`。

### 文件管理

路由：`/files`

文件管理用于查看和标记全局文件资源。

- 支持按文件名或标签搜索。
- 支持按已有标签筛选。
- 内置快捷标签：首帧、尾帧、关键帧、成片、版本 1、现实主义、科幻、待导出。
- 支持多选文件并批量导出。
- 文件以卡片展示，区分图片和视频图标。
- 卡片展示文件名、类型或创建时间、标签和单文件导出入口。
- 当前快捷标记交互为前端 Mock 提示，真实标签写入能力需后端接口配合。

### Agent 管理

路由：`/agents`、`/agents/:id/edit`

Agent 管理用于后续配置不同创作阶段的自动化 Agent。

- 类型包含剧情提取、角色提取、场景提取、道具提取和其他类型。
- 支持按类型 Tab、左侧类型树、名称、类型、描述、创建者搜索。
- 支持最近更新和名称排序。
- 支持表格视图和卡片视图切换。
- 支持详情面板、编辑入口、测试入口、复制、导出、删除和设为默认等交互入口。
- 当前 Agent 后端接口尚未接入，页面不展示 mock 数据，创建、删除、设为默认等操作处于禁用或提示状态。

### 模型管理

路由：`/models`

模型管理当前聚焦模型供应商和供应商模型配置。

- 支持从系统供应商接口加载供应商列表。
- 供应商展示名称、Base URL、描述、启用状态、API Key 配置状态和更新时间。
- 支持新增、编辑供应商，配置名称、Base URL、API Key、API Secret、描述和启用状态。
- 支持打开供应商详情，查看该供应商下的模型列表。
- 模型支持按全部、文本生成、图片生成、视频生成筛选。
- 支持新增、编辑供应商模型，配置模型名称、模型编码、请求 URL、描述和启用状态。
- 图片模型能力可配置支持比例、质量、分辨率、最大参考图数量、最大提示词长度、生成路径和编辑路径。
- 视频模型能力可配置分辨率、最小时长、最大时长、最大参考图数量、原生音频支持、最大提示词长度、提示词模板类别、参考图 token 风格、提交路径和查询路径模板。

### 系统设置

系统设置包含用户管理、角色管理、菜单管理和音色管理，均需要管理员权限。

#### 用户管理

路由：`/system/users`、`/admin/users`

- 支持分页查询用户。
- 支持按用户 ID、用户名或显示名称筛选。
- 支持创建用户，配置用户名、显示名称、密码、角色、API 额度和额度重置时间。
- 支持编辑用户，更新用户名、密码、角色、API 额度、额度重置时间和启停状态。
- 用户列表展示用户 ID、用户名、显示名称、角色、状态、API 用量和额度重置时间。
- 创建用户使用注册接口，编辑用户使用系统用户更新接口。

#### 角色管理

路由：`/system/roles`

- 支持加载角色列表和菜单树。
- 支持创建、编辑、删除角色。
- 角色字段包含角色编码、角色名称、说明、权限编码、菜单绑定和启停状态。
- 权限编码支持 `*`、系统角色读写、系统菜单读写、项目读写、任务读写等预设项。
- 角色列表展示权限标签、绑定菜单数量、系统/自定义类型、启停状态和说明。

#### 菜单管理

路由：`/system/menus`

- 支持从后端加载完整菜单树。
- 支持新增一级菜单和新增子级菜单。
- 支持编辑菜单名称、编码、路由路径、图标、菜单类型、排序和启停状态。
- 支持中英文菜单名称维护，编辑时读取菜单详情；侧边栏和角色权限树随当前语言刷新。
- 菜单类型包含目录、菜单、按钮。
- 支持删除菜单节点，是否允许删除含子节点菜单由后端校验。
- 图标字段接入 `MenuIconPicker` 和 `MenuIconPreview`，可在列表中预览图标。

#### 音色管理

路由：`/system/voices`

- 用于管理系统音色库，支持系统音色、克隆音色、自定义音色的统一列表展示。
- 支持按来源、性别、年龄段、语言和关键词筛选，并支持分页。
- 支持在线试听、暂停、继续播放，并对试听音频做前端缓存。
- 支持新增和编辑系统音色，配置供应商编码、供应商音色 ID、性别、年龄段、语言、主语言、情绪可调、试听 URL、试听文案和排序。
- 支持删除系统音色，删除前会二次确认。
- 接口：GET `/api/v1/studio/voices/available/page`，POST `/api/v1/studio/voices/system/create|update|delete`。

### 效能总览

路由：`/efficiency-overview`

效能总览通过专用服务端统计接口分析用量、生成效率和任务产出，不再由前端临时汇总任务列表或将积分固定为零。

- 支持今日、昨日、近 7 天、近 30 天和自定义日期范围。
- 指标包含积分、耗时分钟数和生成次数。
- 生成次数可按全部、视频、图片、资产图范围统计，支持项目和成员筛选；日期按上海时区处理。
- 展示服务端统计快照对应的汇总、趋势、比较值、项目及成员排行、模型消费分布和业务分类。
- 支持从图表或排行钻取贡献明细，分页查看来源记录，并导出当前筛选条件下的全部匹配 CSV 明细。
- 展示覆盖范围、不完整数据及统计未就绪提示，区分加载、失败、未知值和真实零值，各区域可重试。
- 图表使用 ECharts；客户端由 [效能统计 OpenAPI 契约](docs/contracts/efficiency-overview.openapi.json) 生成，统计口径和可用范围以服务端返回为准。

## 技术与接口说明

- 前端技术栈：React 18、TypeScript、Vite、Ant Design、Tailwind CSS、Zustand、i18next、React Router；3D 编辑使用 Three.js / React Three Fiber，统计图表使用 ECharts。
- 后端接口主要通过 OpenAPI 生成的 `src/services/generated` 访问。
- 部分系统接口使用手写轻量封装，例如提示词模板、模型供应商、剧本导入和资产实体接口。
- 自由画布通过画布后端保存云端工程、素材及任务；localStorage 和 IndexedDB 用于草稿、缓存、请求恢复和旧本地画布。新增能力仍需匹配后端版本、模型配置及权限后联调。
- 当前仓库包含全局暗色主题、主应用国际化资源和画布运行时样式隔离。
