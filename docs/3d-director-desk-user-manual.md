# Reelmax 3D 导演台用户操作手册

> 适用对象：第一次接触 3D、不会建模、不会使用专业动画软件，但希望为项目片段提供画面参考、视频参考或运镜参考的用户。
> 本手册按当前 Reelmax 前端界面编写，覆盖独立导演台和项目片段中的云工程流程。

## 一句话说明

3D 导演台的作用是：**在 3D 场景里摆放角色、道具和摄影机，设计构图和运镜，然后把当前画面或参考视频应用到项目片段的图片/视频生成流程。**

它不是直接生成真人成片的 AI 模型，而是一个可视化导演工具。你可以用它完成：

- 搭建角色站位、道具位置和镜头构图。
- 设计摄影机移动路线，并导出本地 MP4 运镜参考。
- 将当前画面导出为垫图，应用到片段图片生成。
- 将参考视频导出并应用到片段视频参考区。
- 保存云工程、恢复草稿、查看历史修订，并追溯某个生成结果来自哪个导演台修订。

如果你只想快速完成一次项目片段参考，优先阅读“项目片段最快流程”。如果只是练习 3D 运镜，阅读“独立练习最快流程”。

## 核心概念

| 名称 | 含义 |
| --- | --- |
| 导演台 | 3D 编辑器本身，用来摆放物体、调整机位、制作运镜。 |
| 云工程 | 保存在后端的导演台工程，可跨页面、跨设备继续编辑。 |
| 草稿 | 尚未发布为正式版本的云端编辑内容。草稿可恢复，也可丢弃。 |
| 正式版本 | 点击“保存”发布后的云工程版本，会产生修订号。 |
| 修订号 | 云工程的历史版本编号，用于回看、复制、追溯来源。 |
| 片段 | 项目第四步中的分镜片段。导演台产物通常应用到某个片段。 |
| 垫图 | 从导演台导出的当前画面图片，用于片段图片生成。 |
| 参考视频 | 从导演台导出的短视频，用于片段视频参考。 |
| 云素材 | 云工程依赖的模型、贴图等文件。换设备时需要靠云素材恢复。 |
| 角色绑定 | 将导演台中的 3D 角色绑定到项目资产中的角色图，生成时保持人物一致性。 |

## 项目片段最快流程

适合目标：为项目中的某个分镜片段制作图片或视频参考。

### 第 1 步：从片段进入导演台

1. 进入项目创建流程的分镜片段编辑页。
2. 选择一个已有片段。
3. 点击片段编辑区中的 **3D 导演台** 入口。
4. 如果该片段还没有导演台云工程，系统会提示新建或选择云工程。
5. 如果该片段已有多个候选云工程，在 **选择片段云工程** 中选择一个打开。

建议优先从片段进入导演台，这样云工程会自动关联目标片段，后续应用垫图或参考视频时不需要手动填写片段 ID。

### 第 2 步：打开或创建云工程

进入导演台后，顶部会出现云工程工具栏：

- **云工程**：打开云工程列表、搜索工程、切换工程。
- **保存**：发布当前草稿为正式版本。
- **角色绑定**：把 3D 角色与项目角色资产绑定。
- **云素材**：上传当前工程依赖的本地模型和贴图。
- **产物与历史**：查看已导出的垫图/视频和历史修订。
- **导出并上传**：导出垫图或参考视频，并上传到当前片段。

如果当前显示“本地工程”，说明还没有打开可保存的云工程。点击 **云工程** 后可以：

- 打开已有工程。
- 新建空工程。
- 将当前场景另存为新云工程。

### 第 3 步：搭建画面

1. 添加角色、道具或导入模型。
2. 在场景中移动、旋转、缩放对象。
3. 调整摄影机或使用导演视角观察构图。
4. 如果需要固定角色身份，点击 **角色绑定**。
5. 在角色绑定窗口中刷新角色候选，选择对应的项目角色图。
6. 绑定后点击 **保存**，把绑定关系发布到云工程正式版本。

简单理解：导演台负责“角色站在哪里、镜头怎么看”；项目资产负责“这个角色长什么样”。

### 第 4 步：导出垫图并应用到片段图片

1. 调整好当前画面。
2. 点击顶部 **导出并上传**。
3. 选择 **导出垫图并上传**。
4. 上传完成后会打开 **垫图参考** 窗口。
5. 勾选或取消 **附带角色参考图**。
6. 点击 **应用到片段图片**。
7. 需要立即生成图片时，选择图片模型、分辨率、质量，填写提示词，再点击 **生成图片**。

注意：

- “应用到片段图片”只保存参考关系，不一定立刻发起生成。
- 如果只是先把导演台画面绑定到片段，可以先应用，回到片段页后再生成。
- 如果使用角色绑定，提示词里仍建议写清楚“第 1 张角色图对应画面左侧人物”等对应关系。

### 第 5 步：导出参考视频并应用到片段视频

1. 打开运镜工作台，准备好至少 2 个镜头点。
2. 点击顶部 **导出并上传**。
3. 选择 **导出参考视频并上传**。
4. 上传完成后会打开 **垫图参考** 窗口，并以视频形式预览。
5. 点击 **加载视频模型**，选择目标视频模型。
6. 可点击 **读取参考区** 查看当前片段已有参考。
7. 按需勾选 **附带角色参考图**。
8. 点击 **应用到片段视频**。
9. 返回片段编辑页，刷新参考与产物后，再从片段页发起视频生成。

注意：

- 参考视频只作为视频生成参考，不会自动生成最终视频。
- 应用成功后，原有参考会保留，新的导演台参考会追加进去。
- 如果模型没有加载或片段参考版本变化，请重新读取参考区后再应用。

### 第 6 步：回到片段页查看结果

回到项目分镜编辑页后，你可以：

- 查看片段当前应用的 **导演台图片参考**。
- 在生成历史中查看图片或视频结果。
- 对图片结果点击 **图生视频**。
- 对历史产物点击 **查看导演台来源**，追溯它使用了哪个导演台工程和修订。

当你需要修改画面时，建议从来源修订打开导演台，复制当前修订继续编辑，避免覆盖已经用于生成的版本。

## 独立练习最快流程

适合目标：不依赖项目片段，只想练习 3D 运镜并导出本地 MP4。

1. 在 Reelmax 左侧菜单点击 **3D 导演台**。
2. 点击 **云工程**，新建空工程或打开已有工程。
3. 点击 **添加角色**，选择默认角色。
4. 使用移动、旋转、缩放工具调整角色位置。
5. 点击顶部 **运镜**。
6. 在 **一键镜头** 中选择角色和预设，例如推进、环绕或拉远。
7. 点击 **看路线** 检查摄影机轨迹。
8. 点击 **看成片** 检查最终画面。
9. 打开运镜导出面板，选择 `720p + 30 FPS`。
10. 点击 **导出 MP4**，等待浏览器下载视频。

首次练习建议先用 720p。构图和路线都确认无误后，再导出 1080p。

## 云工程管理

### 打开云工程

1. 点击顶部 **云工程**。
2. 在弹窗左侧查看工程列表。
3. 可以通过搜索框搜索工程名称。
4. 点击 **打开** 进入工程。
5. 当前打开的工程会显示“当前”标记。

如果从项目片段进入，弹窗标题可能是 **选择片段云工程**，列表会优先展示与该片段相关的工程。

### 新建云工程

1. 点击顶部 **云工程**。
2. 在右侧 **创建新工程** 中填写工程名称。
3. 点击 **新建空工程**，创建一个空场景。
4. 如果当前已经搭好场景，也可以点击 **当前场景另存为**。

“当前场景另存为”适合在已有构图基础上复制出一个新方案。

### 保存和草稿

云工程有两层保存：

- 草稿保存：系统会尝试保存尚未发布的编辑内容。
- 正式保存：点击 **保存** 后发布为正式版本，并更新修订号。

顶部状态可能显示：

| 状态 | 含义 |
| --- | --- |
| 未保存 | 当前场景和正式版本不同，需要点击保存。 |
| 草稿已保存，尚未发布 | 变更已经进入云草稿，但还不是正式版本。 |
| 正式版本已保存 | 当前内容已发布为正式版本。 |
| 草稿基础版本冲突 | 别处已有更新，当前草稿不能直接覆盖最新版。 |
| 正式发布失败 | 草稿仍保留，需要核对云端状态后重试。 |

如果出现 **发现云草稿**：

- 点击 **恢复草稿**：继续上次未发布的编辑。
- 点击 **丢弃草稿并打开正式版**：放弃草稿，打开最新正式版本。

如果草稿基于旧版本，建议先另存副本或核对云端版本，避免覆盖别人或另一窗口的修改。

### 历史修订

1. 点击 **产物与历史**。
2. 在历史修订列表中选择某个修订查看。
3. 需要继续编辑历史版本时，点击 **复制当前修订继续编辑**。

历史修订适合做来源追溯，不建议直接在旧版本上覆盖最新工程。

### 删除云工程

在云工程列表中点击删除按钮可以删除工程。删除后：

- 工程不再作为普通候选继续编辑。
- 历史产物通常仍可保留。
- 已用于生成的来源修订仍可能被查看。

删除前请确认不再需要继续编辑该工程。

## 云素材管理

云素材用于保存云工程依赖的本地模型、贴图等文件。它解决的是“换设备后模型文件找不到”的问题。

### 什么时候需要上传云素材

建议在以下情况上传云素材：

- 导入了本地 `.fbx`、`.obj`、`.glb` 模型。
- 模型依赖外部贴图或材质文件。
- 需要在另一台电脑继续打开云工程。
- 要将当前场景另存为云工程，并希望素材也能恢复。

### 上传方式

1. 打开一个可编辑云工程。
2. 点击顶部 **云素材**。
3. 选择需要上传的文件或文件夹。
4. 点击上传保存。
5. 上传完成后，点击 **保存** 发布正式版本。

如果只保存本地场景，不上传依赖素材，其他设备打开时可能只能看到空模型、灰模或缺失贴图。

### 常见注意事项

- 尽量把模型和贴图放在同一个文件夹中再上传。
- 不要随意重命名贴图文件，否则模型可能找不到材质。
- 大模型上传需要等待，请不要中途关闭页面。
- 如果提示素材校验失败，重新选择原始文件或文件夹上传。

## 角色绑定

角色绑定用于告诉系统：导演台中的某个 3D 人物，对应项目资产中的哪个角色图。

### 绑定步骤

1. 打开已关联片段的云工程。
2. 点击顶部 **角色绑定**。
3. 点击 **刷新角色候选**。
4. 在每个 3D 角色下拉框中选择对应的角色造型参考图。
5. 绑定后点击 **保存**。

绑定成功后，生成图片或视频时可以附带角色参考图，帮助保持人物一致。

### 绑定状态异常怎么办

如果出现绑定状态警告，常见原因是：

- 原角色资产被删除或不可用。
- 角色图文件缺失。
- 当前工程是历史修订，绑定不再适合最新版。

处理方式：

1. 重新打开 **角色绑定**。
2. 刷新角色候选。
3. 解除失效绑定。
4. 重新选择可用角色图。
5. 点击 **保存**。

## 场景编辑基础

### 左侧：场景层级

场景层级是当前工程的对象列表，常见类型包括：

- 角色。
- 道具和导入模型。
- 摄影机或机位。
- 灯光、地面或辅助对象。

常用操作：

- 单击选中对象。
- 使用眼睛图标显示或隐藏对象。
- 使用锁定图标防止误操作。
- 按住 `Shift` 单击进行多选。
- 选中对象后按 `Delete` 或 `Backspace` 删除。

删除没有反应时，先确认对象没有被锁定，且光标不在输入框中。

### 中间：3D 场景

这里用于摆放角色、观察构图和控制摄影机。

| 操作 | 方法 |
| --- | --- |
| 前后左右移动观察位置 | `W`、`A`、`S`、`D` |
| 上升、下降 | `Space`、`Shift` |
| 环绕观察中心 | 按住鼠标左键拖动 |
| 平移观察中心 | 按住鼠标右键拖动 |
| 靠近或远离场景 | 鼠标滚轮 |

导演视角只是编辑场景时的观察位置，不一定等于最终成片机位。最终视频以活动摄影机的第一视角为准。

### 右侧：属性面板

选中不同对象时，右侧面板内容会变化。

选中角色时，常见页签包括：

- **属性**：名称、位置、旋转、缩放。
- **姿势**：静态姿态。
- **动作**：播放内置动作或导入动作。
- **路线**：设置人物移动路线。

选中摄影机时，可以设置：

- 摄影机名称。
- 当前活动机位。
- 摄影机位置和朝向。
- FOV，也就是视野范围。
- 镜头轨迹和机位截图。

### 顶部：常用工具

| 工具 | 用途 |
| --- | --- |
| 导演视角 | 从场外观察和编辑整个场景。 |
| 第一视角 | 从活动摄影机查看画面。 |
| 运镜 | 打开运镜工作台，制作和导出镜头。 |
| 移动 | 改变对象位置。 |
| 旋转 | 改变对象朝向。 |
| 缩放 | 改变对象大小。 |
| 添加角色 | 添加预设角色、骨骼角色、群众或几何体。 |
| 导入本地模型 | 导入 FBX、OBJ、GLB 文件。 |
| 模型库 | 从内置模型或“我的模型”中加入对象。 |
| 添加机位 | 以当前导演视角创建一个摄影机。 |

## 如何正确导入模型

### 从模型库导入

1. 点击顶部 **模型库**。
2. 选择模型分类。
3. 单击模型卡片，模型会加入当前场景。
4. 在左侧场景层级找到新对象并选中。
5. 使用移动、旋转、缩放调整位置。

### 从电脑导入

当前支持：

- `.fbx`
- `.obj`
- `.glb`

普通静态模型适合作为道具。需要播放人物动作时，优先使用带骨骼和动画的角色模型，并通过角色导入入口添加。

如果模型导入后看不到：

1. 在左侧场景层级确认是否已经出现模型名称。
2. 选中模型，检查 X、Y、Z 是否离场景中心太远。
3. 检查缩放值是否太小或太大。
4. 检查对象是否被隐藏。
5. 尝试聚焦所选对象，再重新调整视角。

导入本地模型后，如果要跨设备使用，请记得上传 **云素材**。

## 角色动作和人物路线

角色动作和摄影机运镜是两件不同的事：

- **角色动作**：人物在原地走、跑或做动作。
- **人物路线**：人物从场景中的一个位置移动到另一个位置。
- **镜头路线**：摄影机如何移动，是导出视频必须关注的路线。

只做一个静止角色的推拉镜头时，不需要人物路线。

### 播放角色动作

1. 在左侧选中角色。
2. 打开右侧 **动作**。
3. 选择内置动作，或导入角色动作文件。
4. 使用 `Space` 播放或暂停人物动作。

### 制作人物移动路线

1. 选中角色。
2. 打开右侧 **路线**。
3. 添加人物路径点。
4. 设置路径时长和移动方式。
5. 播放检查人物是否穿过道具或离开地面。

人物在移动时，镜头可以跟踪人物，让主体尽量保持在画面中。

## 运镜工作台

点击顶部 **运镜** 打开运镜工作台。系统会准备一个可用于运镜的摄影机。

### 一键镜头

适合不熟悉摄影机操作的用户。

1. 在 **跟踪主体** 中选择角色或物体。
2. 选择基础预设或群友预设。
3. 调整 **轨迹范围**。
4. 点击 **看路线** 检查轨迹。
5. 点击 **看成片** 检查最终画面。
6. 不满意时换一个预设，或手动修改轨迹点。

“固定当前画面中心”表示镜头不绑定某个对象，而是围绕当前画面中心生成路线。

### 手动掌镜

适合需要精确构图的用户。

1. 点击 **开始掌镜**。
2. 单击一次 3D 画面，让鼠标进入掌镜状态。
3. 使用 `WASD`、`E`、`Q` 和鼠标移动镜头。
4. 每到一个关键位置按 `Enter`。
5. 至少记录 2 个点。
6. 按 `Esc` 退出。

也可以不进入掌镜模式：先在导演视角调整到想要的位置，然后点击 **添加当前视角**。

### 镜头路线

每个编号代表一个摄影机关键位置。视频播放时，摄影机会按顺序经过这些点。

可以对轨迹点执行：

- 选择和预览。
- 在两个点之间插入新点。
- 将点提前或后移。
- 编辑该点的机位。
- 删除该点。
- 批量选择并移动多个点。
- 设置中间点的到达时间。

### 镜头速度和停留

- **匀速**：整段运动速度基本一致。
- **柔和**：起步和停止更平滑，适合大多数镜头。
- **自定义**：用于更精细的节奏控制。
- **经过**：摄影机不停下来，直接经过当前点。
- **停留**：摄影机到达当前点后暂停一段时间。

初学者建议优先使用“柔和”，避免镜头突然启动或停止。

### 跟踪主体

轨迹点可以指定跟踪对象：

- 跟踪角色时，可以选择身体部位。
- 跟踪普通物体时，通常对准物体中心。
- “立即”响应会快速对准主体。
- “平滑”响应会逐渐转向主体，画面更自然。
- 防抖可减轻跟随人物动作时的抖动。

如果画面摇晃明显，优先尝试“平滑”跟随和防抖。

## 导出和上传

导演台现在有两类导出：

| 导出方式 | 用途 | 结果 |
| --- | --- | --- |
| 运镜工作台里的 **导出 MP4** | 本地下载运镜参考视频 | 浏览器下载 MP4 文件 |
| 顶部 **导出并上传 > 导出垫图并上传** | 给片段图片生成提供画面参考 | 上传图片并打开应用窗口 |
| 顶部 **导出并上传 > 导出参考视频并上传** | 给片段视频生成提供参考视频 | 上传视频并打开应用窗口 |

### 导出本地 MP4

1. 打开 **运镜**。
2. 确认镜头路线至少有 2 个点。
3. 点击 **导出**。
4. 选择画质：
   - `720p`：导出快，适合测试。
   - `1080p`：画面更清晰，适合最终参考视频。
5. 选择帧率：
   - `24 FPS`：接近电影感，文件较小。
   - `30 FPS`：通用推荐。
   - `60 FPS`：更流畅，但对电脑性能要求更高。
6. 点击 **导出 MP4**。
7. 录制完成前不要关闭页面、切换导演台或让电脑休眠。

### 导出垫图并上传

1. 调整好当前画面。
2. 点击顶部 **导出并上传**。
3. 选择 **导出垫图并上传**。
4. 上传完成后在弹窗中预览图片。
5. 点击 **应用到片段图片**，或继续填写提示词并点击 **生成图片**。

### 导出参考视频并上传

1. 准备好运镜路线。
2. 点击顶部 **导出并上传**。
3. 选择 **导出参考视频并上传**。
4. 上传完成后在弹窗中预览视频。
5. 选择视频模型。
6. 点击 **应用到片段视频**。
7. 回到片段页发起最终视频生成。

## 保存、备份和换设备

### 当前推荐保存方式

1. 打开或创建云工程。
2. 编辑场景。
3. 如果导入了本地模型，先上传 **云素材**。
4. 点击 **保存** 发布正式版本。
5. 重要节点可以在 **产物与历史** 中确认修订。

### 仍需注意

- 草稿不是正式版本，协作或换设备前请点击 **保存**。
- 本地导入模型如果没有上传云素材，换设备后可能丢失。
- 浏览器本地缓存可能保存临时状态，但不要把它当作唯一备份。
- 清除浏览器数据、使用无痕窗口或换浏览器，可能丢失本地临时内容。
- 历史修订适合回看和复制，不建议直接覆盖最新版本。

### 建议备份习惯

- 关键场景完成后点击 **保存**。
- 复杂工程保留清晰的工程名称。
- 本地模型、贴图原始文件单独归档。
- 重要方案可通过“当前场景另存为”保留分支。

## 常见问题排查

### 1. 我完全不知道从哪里开始

如果是项目片段：**进入分镜片段 > 打开 3D 导演台 > 新建云工程 > 摆角色和镜头 > 角色绑定 > 导出垫图并上传 > 应用到片段图片**。

如果只是练习运镜：**新建云工程 > 添加默认角色 > 运镜 > 一键镜头 > 看成片 > 720p/30 FPS 导出 MP4**。

### 2. 保存按钮点了但提示草稿冲突

说明正式版本可能已经被其他窗口或设备更新。建议：

1. 不要反复点击保存。
2. 点击核对云端草稿。
3. 需要保留当前内容时，先另存为新工程。
4. 确认后再决定丢弃草稿或复制修订继续编辑。

### 3. 打开工程时提示发现云草稿

如果想继续上次编辑，点击 **恢复草稿**。如果确定不要上次编辑，点击 **丢弃草稿并打开正式版**。

### 4. 换电脑后模型或贴图丢失

通常是没有上传云素材。回到原设备：

1. 打开该云工程。
2. 点击 **云素材**。
3. 上传模型和贴图所在文件夹。
4. 点击 **保存** 发布正式版本。
5. 再在新设备打开。

### 5. 角色绑定里没有候选角色

检查：

1. 当前工程是否关联了项目片段。
2. 片段是否已经有可用角色资产。
3. 点击 **刷新角色候选**。
4. 如果仍为空，回项目资产步骤确认角色图是否已生成或导入。

### 6. “应用到片段视频”按钮不能用

常见原因：

- 没有选择视频模型。
- 参考视频还没有上传完成。
- 目标片段 ID 不正确。
- 参考区版本已变化，需要重新读取参考区。

### 7. 片段页看不到刚应用的参考

回到片段页后刷新参考与产物。如果仍看不到：

1. 确认应用时选择的是正确片段。
2. 确认弹窗提示应用成功。
3. 重新打开 **导演台图片参考** 或刷新视频参考区。

### 8. 导出 MP4 按钮是灰色

当前活动摄影机的镜头路线少于 2 个轨迹点。套用一键镜头，或者在两个不同位置按 `Enter` 记录镜头。

### 9. 提示当前浏览器不支持 MP4 导出

请使用最新版 Chrome 或 Edge。导出依赖浏览器的 MP4 录制能力，部分浏览器不支持。

### 10. 导出一直没有结束

导出是实时录制。先等待与视频时长相同的时间，并留出编码时间。导出期间不要关闭页面、切换导演台或让电脑休眠。

### 11. 导出的视频是黑屏或画面不对

1. 先点击 **看成片**，确认第一视角能正常播放。
2. 确认当前活动机位是正确机位。
3. 等待本地模型和贴图加载完成。
4. 检查摄影机是否进入模型内部、地面以下或背对主体。
5. 删除异常轨迹点后重新记录。

### 12. 导出的视频为什么没有声音

这是当前功能的正常表现。导演台导出的是无音轨的 3D 运镜参考视频，声音需要在后期剪辑或视频生成流程中处理。

### 13. 鼠标不能控制摄影机

点击 **开始掌镜** 后，还需要单击一次 3D 画面，让浏览器锁定鼠标。按 `Esc` 会解除锁定。

### 14. 播放时镜头突然转向或抖动

1. 检查该轨迹点是否跟踪了错误对象。
2. 将跟随响应改为“平滑”。
3. 开启防抖。
4. 删除位置过近或方向差异过大的轨迹点。

### 15. 场景变卡

1. 删除暂时不需要的高精度模型或大量群众对象。
2. 降低显示性能设置。
3. 首次测试使用 720p、24 或 30 FPS。
4. 关闭其他占用显卡的网页或软件。
5. 不要同时播放大量角色动画。

## 新手推荐的第一条项目镜头

可以照下面的方式练习一次：

1. 在项目分镜编辑页选择一个片段。
2. 打开 **3D 导演台**。
3. 新建或打开片段云工程。
4. 添加一个默认角色，放在场景中心。
5. 绑定项目中的对应角色图。
6. 打开运镜，跟踪主体选择该角色。
7. 选择一个推进或轻微环绕预设。
8. 轨迹范围设置为 75% 至 100%。
9. 整段时长设置为 6 秒。
10. 先看路线，再看成片。
11. 点击 **导出并上传 > 导出垫图并上传**。
12. 点击 **应用到片段图片**。
13. 回片段页生成图片或继续图生视频。

这个练习完成后，你就掌握了当前导演台和项目片段联动的核心流程。
