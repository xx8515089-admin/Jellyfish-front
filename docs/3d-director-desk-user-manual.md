# Reelmax 3D 导演台用户手册

> 适用对象：第一次接触 3D、不会建模、不会使用专业动画软件的普通用户。  
> 本手册按 Reelmax 当前界面和实际功能编写。

## 一句话说明

3D 导演台的工作方式是：**把角色、道具和机位放进一个 3D 场景，记录摄影机移动路线，预览镜头，然后导出 MP4 参考视频。**

它当前导出的是干净的 3D 运镜参考视频，不是调用 AI 自动生成的真人成片。导出视频中不包含操作界面、轨迹线和声音。你可以把它用于：

- 预演机位和运镜。
- 给分镜、动画、拍摄或 AI 视频生成提供镜头参考。
- 快速验证“角色放在哪里、镜头怎么走、画面能不能成立”。

如果你只想尽快做出第一段视频，直接从下一节开始，暂时不用学习后面的高级功能。

---

## 10 分钟做出第一段视频

### 第 1 步：进入或新建导演台

1. 在 Reelmax 左侧菜单点击 **3D 导演台**。
2. 在“我的导演台”区域中：
   - 已有导演台：点击对应卡片进入。
   - 第一次使用：点击 **新建导演台**，系统会创建一个独立场景。

导演台会自动保存到当前浏览器。进入后看到的主要区域是：

- 左侧：场景层级，列出角色、道具、机位。
- 中间：3D 场景，是摆放物体和观察镜头的地方。
- 右侧：当前选中对象的属性、姿势、动作、路线等设置。
- 顶部：视角、运镜、模型导入、截图和显示设置。

### 第 2 步：放入一个角色

最简单的方法：

1. 点击场景上方工具栏的 **添加角色**。
2. 选择一个内置人体类型。
3. 角色出现在场景中后，在左侧场景层级点击角色名称。
4. 使用工具栏的 **移动、旋转、缩放** 调整角色。

也可以使用以下方式：

- **模型库**：打开模型库，选择分类，单击模型卡片即可加入场景。
- **导入本地模型**：导入 `.fbx`、`.obj` 或 `.glb` 文件。
- **添加角色 > 导入角色**：用于导入带骨骼、可播放动作的角色模型。
- **添加角色 > 几何模型**：先用简单几何体代替道具进行镜头测试。

第一次练习不需要精细模型，一个默认角色就够了。

### 第 3 步：调整角色位置

1. 在左侧场景层级选中角色。
2. 在场景上方选择 **移动** 工具。
3. 拖动红、绿、蓝三个方向轴调整位置。
4. 需要调整朝向时切换到 **旋转**。
5. 需要调整大小时切换到 **缩放**。

如果拖动困难，也可以在右侧属性面板中直接填写 X、Y、Z 数值。

### 第 4 步：打开运镜工作台

点击页面顶部的 **运镜**。

系统会打开运镜工作台，并自动准备一个可用于运镜的摄影机。此时有两种做法：

#### 方法 A：一键镜头，最适合第一次使用

1. 在 **一键镜头** 区域找到“跟踪主体”。
2. 选择刚才加入场景的角色。
3. 在镜头预设中选择一个效果，例如环绕、推进或拉远。
4. 用“轨迹范围”调整镜头运动幅度：
   - 画面变化太小：向右调大。
   - 镜头离得太远或动作太夸张：向左调小。
5. 套用预设后，下面的“镜头路线”会出现多个编号点。

只要镜头路线中至少有 2 个点，就具备导出视频的基本条件。

#### 方法 B：自己掌镜，适合精确控制

1. 点击 **开始掌镜**。
2. 单击一次中间的 3D 画面，让鼠标进入掌镜状态。
3. 使用以下按键移动摄影机：

| 操作 | 按键 |
| --- | --- |
| 前进、后退、左移、右移 | `W`、`S`、`A`、`D` |
| 上升、下降 | `E`、`Q` |
| 改变镜头朝向 | 移动鼠标 |
| 调整视野大小 | 鼠标滚轮 |
| 记录当前镜头位置 | `Enter` |
| 退出鼠标锁定 | `Esc` |

4. 走到第一个合适的位置，调整好朝向，按 `Enter` 记录第 1 个点。
5. 移动到下一个位置，再按 `Enter` 记录第 2 个点。
6. 根据需要继续移动并按 `Enter`，增加更多镜头点。
7. 完成后按 `Esc` 退出掌镜。

最短路线只需要 2 个点，例如：

- 第 1 点：角色全身远景。
- 第 2 点：缓慢推进到角色半身。

### 第 5 步：检查路线和成片

运镜工作台提供两种预览：

- **看路线**：用导演视角观察摄影机如何移动，方便检查轨迹点是否绕错方向、穿过物体或离主体太远。
- **看成片**：直接从摄影机第一视角观看最终画面。这才是导出视频接近的效果。

建议按这个顺序检查：

1. 先点 **看路线**，确认路线正确。
2. 再点 **看成片**，检查构图和节奏。
3. 拖动底部时间轴，逐段检查镜头。
4. 如果镜头不合适，选中对应轨迹点进行修改或删除。

### 第 6 步：调整视频时长

在运镜设置中调整整段镜头时长。时长越短，摄影机移动越快；时长越长，镜头移动越慢。

第一次练习建议：

- 2 个镜头点：设置为 4 至 6 秒。
- 3 至 5 个镜头点：设置为 6 至 12 秒。
- 镜头需要停留时：选中轨迹点，将点行为改成“停留”，再设置停留时间。

### 第 7 步：导出 MP4 视频

1. 在运镜工作台右上角点击 **导出**。
2. 选择画质：
   - `720p`：导出快，适合测试。
   - `1080p`：画面更清晰，适合最终参考视频。
3. 选择帧率：
   - `24 FPS`：接近电影感，文件较小。
   - `30 FPS`：通用推荐。
   - `60 FPS`：更流畅，但对电脑性能要求更高。
4. 点击 **导出 MP4**。
5. 页面会从时间轴起点开始实时录制。录制完成前不要关闭页面或切换导演台。
6. 完成后浏览器会自动下载一个名称类似“机位名称-参考视频.mp4”的文件。

首次测试推荐使用 **720p + 30 FPS**。确认路线、构图和时长都正确后，再导出 **1080p + 30 FPS**。

> 重要：导出是按视频时长实时录制的。10 秒视频通常至少需要等待约 10 秒，再加少量编码时间。

## 导出按钮为什么点不了

“导出 MP4”按钮变灰时，通常只有一个原因：**当前活动机位的镜头路线少于 2 个轨迹点。**

按下面顺序检查：

1. 运镜工作台的“镜头路线”是否显示至少 2 个编号点。
2. 如果有多个机位，当前选中的是否是有路线的机位。
3. 如果没有点：
   - 套用一个“一键镜头”预设；或者
   - 点击“开始掌镜”，在两个不同位置分别按一次 `Enter`；或者
   - 调整导演视角后，连续两次使用“添加当前视角”，并改变两次视角的位置。
4. 点击 **看成片**，能正常播放后再导出。

## 3D 导演台完整界面说明

### 左侧：场景层级

场景层级相当于当前导演台的物品清单，常见类型包括：

- 角色。
- 道具和导入模型。
- 摄影机或机位。
- 灯光、地面或辅助对象。

在这里可以：

- 单击选中对象。
- 使用眼睛图标显示或隐藏对象。
- 使用锁定图标防止误操作。
- 按住 `Shift` 单击进行多选。
- 选中对象后按 `Delete` 或 `Backspace` 删除。

删除没有反应时，先确认：

1. 对象没有被锁定。
2. 光标不在输入框中。
3. 已在场景层级或 3D 画面中真正选中对象。

### 中间：3D 场景

这里用于摆放角色、观察构图和控制摄影机。

在导演视角中：

| 操作 | 方法 |
| --- | --- |
| 前后左右移动观察位置 | `W`、`A`、`S`、`D` |
| 上升、下降 | `Space`、`Shift` |
| 环绕观察中心 | 按住鼠标左键拖动 |
| 平移观察中心 | 按住鼠标右键拖动 |
| 靠近或远离场景 | 鼠标滚轮 |

导演视角只是你操作场景时的观察位置，不一定等于最终成片机位。最终视频以当前活动摄影机的第一视角为准。

### 右侧：属性面板

右侧面板会根据选中的对象变化。

选中角色时，常见页签包括：

- **属性**：名称、位置、旋转、缩放等。
- **姿势**：静态姿态。
- **动作**：播放内置动作或导入自定义动作。
- **路线**：设置人物自己的移动路线。

选中摄影机时，可以设置：

- 摄影机名称。
- 当前活动机位。
- 摄影机位置和朝向。
- FOV，也就是视野范围。
- 镜头轨迹和机位截图。

### 顶部：常用工具

| 工具 | 用途 |
| --- | --- |
| 导演视角 | 从场外观察和编辑整个场景 |
| 第一视角 | 从活动摄影机查看画面 |
| 运镜 | 打开运镜工作台，制作和导出镜头 |
| 移动 | 改变对象位置 |
| 旋转 | 改变对象朝向 |
| 缩放 | 改变对象大小 |
| 添加角色 | 添加预设角色、骨骼角色、群众或几何体 |
| 导入本地模型 | 导入 FBX、OBJ、GLB 文件 |
| 模型库 | 从内置模型或“我的模型”中加入对象 |
| 添加机位 | 以当前导演视角创建一个摄影机 |

## 如何正确导入模型

### 从模型库导入

1. 点击顶部 **模型库**。
2. 选择模型分类。
3. 单击模型卡片，模型会直接加入当前场景。
4. 关闭模型库，在左侧场景层级找到新对象并选中。
5. 使用移动、旋转、缩放调整位置。

“我的模型”中没有内容时，可以点击 **本地导入**。

### 从电脑导入

当前支持：

- `.fbx`
- `.obj`
- `.glb`

普通静态模型适合作为道具。需要播放人物动作时，优先使用带骨骼和动画的角色模型，并通过角色导入入口添加。

如果模型导入后看不到：

1. 在左侧场景层级确认是否已经出现模型名称。
2. 选中模型，检查 X、Y、Z 是否离场景中心太远。
3. 检查缩放值是否太小或太大。
4. 检查对象是否被隐藏。
5. 尝试锁定或聚焦所选对象，再重新调整视角。

## 角色动作和人物路线

角色动作和摄影机运镜是两件不同的事：

- **角色动作**：人物在原地走、跑或做动作。
- **人物路线**：人物从场景中的一个位置移动到另一个位置。
- **镜头路线**：摄影机如何移动，是导出视频必须关注的路线。

只做一个静止角色的推拉镜头时，不需要人物路线。

### 播放角色动作

1. 在左侧选中角色。
2. 打开右侧 **动作**。
3. 选择内置动作，或导入角色动作文件。
4. 使用 `Space` 播放或暂停人物动作。

### 制作人物移动路线

1. 选中角色。
2. 打开右侧 **路线**。
3. 添加人物路径点。
4. 设置路径时长和移动方式。
5. 播放检查人物是否穿过道具或离开地面。

人物在移动时，镜头可以对人物进行跟踪。这样角色走动时，摄影机仍然会尽量保持主体在画面中。

## 运镜工作台详细说明

### 一键镜头

适合不熟悉摄影机操作的用户。

1. 在“跟踪主体”中选择角色或物体。
2. 选择基础预设或群友预设。
3. 调整“轨迹范围”。
4. 预览路线和成片。
5. 不满意时换一个预设，或者手动修改轨迹点。

“固定当前画面中心”表示镜头不绑定某个对象，而是围绕当前画面中心生成路线。

### 手动掌镜

适合需要精确构图的用户。

1. 点击 **开始掌镜**。
2. 点击画面锁定鼠标。
3. 使用 `WASD`、`E`、`Q` 和鼠标移动镜头。
4. 每到一个关键位置按 `Enter`。
5. 至少记录 2 个点。
6. 按 `Esc` 退出。

也可以不进入掌镜模式：先在导演视角调整到想要的位置，然后点击 **添加当前视角**。

### 镜头路线

每个编号代表一个摄影机关键位置。视频播放时，摄影机会按顺序经过这些点。

可以对轨迹点执行：

- 选择和预览。
- 在两个点之间插入新点。
- 将点提前或后移。
- 编辑该点的机位。
- 删除该点。
- 批量选择并移动多个点。
- 设置中间点的到达时间。

### 镜头速度和停留

- **匀速**：整段运动速度基本一致，最容易理解。
- **柔和**：起步和停止更平滑，适合大多数展示镜头。
- **自定义**：用于更精细的节奏控制。
- **经过**：摄影机不停下来，直接经过当前点。
- **停留**：摄影机到达当前点后暂停一段时间。

初学者建议优先使用“柔和”，避免镜头突然启动或停止。

### 跟踪主体

轨迹点可以指定跟踪对象：

- 跟踪角色时，可以选择身体部位。
- 跟踪普通物体时，通常对准物体中心。
- “立即”响应会快速对准主体。
- “平滑”响应会逐渐转向主体，画面更自然。
- 防抖可减轻跟随人物动作时的抖动。

如果画面摇晃明显，优先尝试“平滑”跟随和防抖。

## 截图和视频有什么区别

导演台中的截图功能用于保存静态画面：

- 当前视角截图。
- 四视图截图。
- 十二方位截图。

截图可以查看、下载或发送到画布，但不会生成动态视频。

要生成视频，必须打开 **运镜工作台 > 导出 > 导出 MP4**。

## 保存、备份和换电脑

### 自动保存

当前导演台会按导演台编号自动保存在浏览器本地。正常编辑后不需要反复点击保存。

### 需要特别注意

- 本地保存不等于云端保存。
- 清除浏览器数据可能导致导演台内容丢失。
- 换浏览器、换电脑或使用无痕窗口时，不一定能看到原来的导演台。
- 本地导入的模型依赖浏览器本地资源，换设备后可能需要重新导入原模型文件。

### 建议的备份方法

1. 定期使用项目导出功能保存项目 JSON。
2. 妥善保存原始 `.fbx`、`.obj`、`.glb` 模型文件。
3. 在另一台电脑恢复时，先导入项目 JSON，再按提示重新导入缺失的本地模型。

## 常见问题排查

### 1. 我完全不知道从哪里开始

使用最短流程：

**新建导演台 > 添加默认角色 > 运镜 > 一键镜头 > 选择角色 > 选择一个预设 > 看成片 > 720p/30 FPS 导出。**

### 2. 导出 MP4 按钮是灰色

当前活动摄影机少于 2 个轨迹点。套用一键镜头，或者在两个不同位置按 `Enter` 记录镜头。

### 3. 提示当前浏览器不支持 MP4 导出

请使用最新版 Chrome 或 Edge。导出依赖浏览器的 MP4 录制能力，部分浏览器不支持。

### 4. 导出一直没有结束

导出是实时录制。先等待与视频时长相同的时间，并留出编码时间。导出期间不要关闭页面、切换导演台或让电脑休眠。

### 5. 导出的视频是黑屏或画面不对

1. 先点击“看成片”，确认第一视角能正常播放。
2. 确认当前活动机位是正确机位。
3. 等待本地模型和贴图加载完成。
4. 检查摄影机是否进入模型内部、地面以下或背对主体。
5. 删除异常轨迹点后重新记录。

### 6. 导出的视频为什么没有声音

这是当前功能的正常表现。导演台导出的是无音轨的 3D 运镜参考视频，声音需要在后期剪辑中添加。

### 7. 鼠标不能控制摄影机

点击“开始掌镜”后，还需要单击一次 3D 画面，让浏览器锁定鼠标。按 `Esc` 会解除锁定。

### 8. 播放时镜头突然转向或抖动

1. 检查该轨迹点是否跟踪了错误对象。
2. 将跟随响应改为“平滑”。
3. 开启防抖。
4. 删除位置过近或方向差异过大的轨迹点。

### 9. 模型导入了但场景里看不到

在左侧场景层级选中模型，检查显示状态、位置和缩放。大多数情况是模型离中心太远，或者缩放比例不合适。

### 10. 场景变卡

1. 删除暂时不需要的高精度模型或大量群众对象。
2. 降低显示性能设置。
3. 首次测试使用 720p、24 或 30 FPS。
4. 关闭其他占用显卡的网页或软件。
5. 不要同时播放大量角色动画。

### 11. 换电脑后模型丢失

项目 JSON 主要保存场景和资源引用，本地模型文件不会自动变成云端资源。请在新设备重新导入原始模型文件。

## 新手推荐的第一条镜头

可以照下面的参数练习一次：

1. 添加一个默认角色，放在场景中心。
2. 打开运镜，跟踪主体选择该角色。
3. 选择一个推进或轻微环绕预设。
4. 轨迹范围设置为 75% 至 100%。
5. 整段时长设置为 6 秒。
6. 速度选择“柔和”。
7. 先看路线，再看成片。
8. 使用 720p、30 FPS 导出测试。
9. 确认满意后改为 1080p、30 FPS 再导出一次。

这个练习完成后，你就已经掌握了 3D 导演台最核心的完整流程。

## 导出前 30 秒检查清单

- [ ] 场景中的角色和道具位置正确。
- [ ] 当前活动机位正确。
- [ ] 镜头路线至少有 2 个点。
- [ ] “看路线”没有穿模或绕错方向。
- [ ] “看成片”构图正确。
- [ ] 视频时长和移动速度合适。
- [ ] 需要跟踪的主体没有选错。
- [ ] 需要停留的轨迹点已设置停留时间。
- [ ] 本地模型和贴图已经加载完成。
- [ ] 首次测试使用 720p、30 FPS。
- [ ] 使用最新版 Chrome 或 Edge。

完成以上检查后，点击 **运镜 > 导出 > 导出 MP4** 即可。
