# 自由画布与 3D 导演台：零基础用户手册

适合第一次使用、不懂节点、不懂 3D 的用户。跟着按钮名称操作即可。

编写依据：2026 年 9 月 21 日的项目界面与功能实现。本文以**云端画布、导演台云工程**为主；模型和部分功能是否可用，以当前账号界面提示为准。

## 1. 先选你要做的事

| 我想做什么 | 用哪个工具 | 看哪一节 |
| --- | --- | --- |
| 输入一句话，生成图片 | 自由画布 | 第 3 节 |
| 让一张人物图、产品图动起来 | 自由画布 | 第 4 节 |
| 一次生成几个镜头 | 自由画布 | 第 5 节 |
| 自己决定人物站位、镜头角度和移动路线 | 3D 导演台 | 第 7、8 节 |
| 把导演台画面用于项目中的 AI 生成 | 3D 导演台 + 项目片段 | 第 9 节 |
| 两个工具一起用 | 先导演台，再自由画布 | 第 10 节 |

**自由画布像一张工作桌**：放上文字、图片和生成工具，用线连接起来。

**3D 导演台像一个小片场**：摆人物、摆道具、摆摄影机，先设计好怎么拍。

第一次不用学完全部功能。建议先做第 3 节的一张图，再做第 7 节的一个推镜。

## 2. 开始前，只认识这几个词

| 页面上的词 | 大白话解释 |
| --- | --- |
| 节点 | 画布上的一个功能方块，例如“图片输入”或“AI 视频”。 |
| 连线 | 告诉系统：把这个方块的内容交给下一个方块。 |
| 提示词 | 用文字告诉 AI 你想要什么。 |
| 模型 | 负责生成图片或视频的 AI 工具。 |
| 分镜 / 镜头 | 一小段连续画面。三个镜头通常会得到三条素材。 |
| 机位 | 摄影机放在哪里、朝哪个方向拍。 |
| 运镜 | 摄影机怎样移动，例如慢慢靠近人物。 |
| 垫图 | 给 AI 参考的图片，用来说明构图、位置等。 |
| 修订 / v1、v2 | 保存下来的第几个版本。 |

先登录账号。涉及 AI 生成时，选择界面中可用的模型，并查看生成前的积分提示。第一次只生成一份结果。

找不到图标含义时，把鼠标放上去，查看按钮提示。下文的 **粗体文字** 是需要寻找的按钮或界面名称。

## 3. 自由画布练习一：生成你的第一张图

目标：做出一张“窗边的橘猫”图片，并下载到电脑。

### 第一步：打开一张新画布

1. 点击系统左侧的 **自由画布**。
2. 在画布列表点击 **新建画布**。
3. 进入后，找到中间可以摆放方块的区域，这就是画布。
4. 点击编辑区顶部的项目名称，改成“橘猫练习”，按 `Enter`。
5. 查看外层顶部是否显示 **云端画布**。

**完成标志：** 进入画布编辑区，能看到项目名称和“保存与同步”区域。

如果显示 **本地画布**，这是旧的本地工作区。可以使用 **复制本地画布到云端**，成功后进入云端副本继续练习。本地数据不要当作已经跨设备保存。

> 新建另一张画布请返回“画布列表”。编辑区名称旁边的小加号是“新建空项目（清空当前内容）”，已有内容时不要把它当成新增画布。

### 第二步：放一个“AI 绘图”方块

1. 在画布**空白位置双击鼠标左键**。
2. 在弹出菜单里点击 **AI 绘图**。
3. 找到新出现节点中的提示词输入框。
4. 复制下面这段文字进去：

```text
一只橘猫坐在木质窗台上，看向窗外。午后暖阳从侧面照进来，
背景是虚化的绿色庭院。写实摄影风格，画面干净，没有文字。
```

**完成标志：** 画布上出现一个绘图节点，输入框里有这段文字。

### 第三步：选模型和画面大小

1. 在节点中选择一个可用的图片模型。
2. 选择画面比例。第一次可以用 `1:1`；模型没有这个选项就保留可用的默认比例。
3. 分辨率先用默认值。
4. 如果有生成数量选项，设为 `1`。

模型列表为空时，点击顶部 **API 设置**，在 **接口与模型** 窗口点击 **刷新配置**。云端模型的供应商密钥由服务端管理，普通用户不需要在这里填写密钥；刷新后仍无可用模型，请联系管理员。

### 第四步：生成并等待结果

1. 点击节点上的 **生成** 按钮，通常是三角形图标。
2. 查看弹出的 **确认生成**，核对预留积分后确认。
3. 打开 **保存与同步 → 历史 / 素材 → 生成任务**。
4. 等任务完成。如果列表没有更新，点击 **刷新**。

**完成标志：** 对应任务显示成功，并出现图片预览。

生成需要等待，时间取决于模型和排队情况。等待期间不要反复点击生成。

### 第五步：把结果放回画布

1. 在成功任务下找到 **应用结果 1**。
2. 点击它，确认将结果放回原节点。
3. 回到画布，检查绘图节点里的图片。

**完成标志：** 节点里能看到橘猫图片。

“任务成功”和“应用到画布”是两步。云端任务的结果会保留在历史中，确认应用后才更新画布内容；应用时会替换目标节点的当前内容。

### 第六步：下载图片，保存工程

1. 在画布中选中已有结果的图片节点，点击顶部 **下载**。
2. 也可以进入 **历史 / 素材 → 素材库**，找到图片并点击 **下载**；必要时先点 **刷新素材**。
3. 回到 **保存与同步**，点击 **保存云端**。
4. 等状态显示 **已保存 · v…**。

**完成标志：** 电脑上有图片文件，画布显示已保存版本。

下载图片是保存成品；保存云端是保存画布上的节点、文字、连线等。做完后这两件事都要确认。

## 4. 自由画布练习二：让图片动起来

目标：让刚才的橘猫轻轻转头，得到一条短视频。

### 第一步：准备图片和视频节点

1. 双击画布空白处，选择 **图片输入**。
2. 在图片输入节点中选择刚下载的橘猫图片。
3. 等到节点里能正常看到图片。
4. 再双击空白处，选择 **AI 视频**。

也可以直接使用上一节已经应用结果的绘图节点作为图片来源。

### 第二步：把图片连到视频节点

1. 找到图片节点边缘的输出小圆点。
2. 按住这个圆点，把线拖向 AI 视频节点的输入小圆点。
3. 到达输入点后松开鼠标。

连接顺序是：**图片 → AI 视频**。

**完成标志：** 两个节点之间出现连线。提交前还要检查 AI 视频节点是否识别到了这张参考图；只把两个节点摆在一起不会传递图片。

### 第三步：写“怎么动”

在 AI 视频节点里输入：

```text
保持参考图中橘猫的外观、窗台和背景不变。
橘猫缓慢转头看向镜头，轻轻眨眼，尾巴小幅摆动。
镜头固定，动作自然，画面稳定，不增加其他动物和文字。
```

第一次只写一个小动作。不要在同一条短视频里同时要求转场、奔跑、变装和快速旋转镜头。

### 第四步：设置并生成

1. 选择支持参考图的视频模型。
2. 检查该模型允许的参考图数量；先用一张图。
3. 比例尽量与参考图一致，分辨率先用默认值。
4. 时长选模型允许的较短选项。
5. 点击生成，查看积分提示并确认。
6. 在 **历史 / 素材 → 生成任务** 中等待结果。
7. 成功后点击 **应用结果 1**，预览视频。
8. 下载视频，再点击 **保存云端**。

**完成标志：** 能播放一条橘猫有动作的视频，并已下载保存。

没有图片时，也可以直接添加 **AI 视频**，选择支持纯文字生成的视频模型，写清“谁、在哪里、做什么、镜头怎么动”后生成。

当前云端画布暂未开放首尾帧、遮罩等部分高级媒体生成方式。第一遍练习使用普通文字生成或单张参考图生成即可。

## 5. 自由画布练习三：一次做三个分镜

目标：把三条镜头描述拆成三行，分别生成视频。

### 第一步：输入三条镜头

1. 双击空白处，添加 **文字节点**。
2. 复制下面的文字：

```text
#1 午后庭院远景，树叶轻轻摇动，阳光洒在石板路上，固定镜头。
#2 橘猫坐在窗台上望向庭院，中景，橘猫轻轻转头，固定镜头。
#3 橘猫面部近景，缓慢眨眼，背景柔和虚化，固定镜头。
```

### 第二步：拆成分镜

1. 双击空白处，添加 **智能分镜表**。
2. 从文字节点的输出点连到分镜表的输入点。
3. 在分镜表顶部切换到 **视频**。
4. 点击 **脚本**，导入并拆分上游文字。

**完成标志：** 分镜表中出现三条镜头，每条都有对应的描述。

如果点击“脚本”只展开了输入框，说明没有识别到上游文字。先检查连线和文字节点内容。

### 第三步：逐条检查

1. 确认每个镜头的提示词正确。
2. 每条选择可用的视频模型。
3. 统一画面比例，例如都用 `16:9`。
4. 设置模型支持的分辨率和时长。
5. 需要同一只猫时，为相关镜头提供同一张角色参考图，并检查模型是否支持。

只有文字描述时，不同镜头生成的角色外观可能有差异。第一次先验证流程，再逐步调整人物或物体的一致性。

### 第四步：提交批量任务

1. 点击分镜表顶部 **批量**，打开云端 **批量生成** 窗口。
2. 在列表中核对并勾选这三个镜头。
3. 把 **每项数量** 设为 `1`，确认共三个任务。
4. 点击 **预估费用**。
5. 核对预留积分及 **预留积分上限**。
6. 确认后点击 **确认提交**。

这里的“每项数量”是每个镜头生成几份结果，不是同时运行多少个任务。预留积分上限约束提交时的预留，并不代表最终实际费用封顶。

### 第五步：领取三个结果

1. 在 **历史 / 素材 → 批次任务** 中看整体进度。
2. 在 **生成任务** 中检查每个镜头的结果。
3. 对满意的结果点击 **应用结果**，放回对应镜头。
4. 下载结果，保存云端。

**完成标志：** 三个镜头都有可播放的视频素材。

批量生成得到的是多条镜头素材。要做成一条完整短片，需要把这些素材放到剪辑工具里，按顺序排列，再添加声音或字幕。

## 6. 自由画布日常操作与保存

### 鼠标怎么用

| 想做什么 | 操作 |
| --- | --- |
| 新增节点 | 双击画布空白处，再选节点类型。 |
| 移动节点 | 按住节点标题或非输入区域拖动。 |
| 移动画布 | 在空白处按住鼠标左键拖动。 |
| 放大、缩小 | 鼠标放在画布空白处滚动滚轮。 |
| 传递图片或文字 | 从上游节点输出点拖到下游节点输入点。 |
| 删除节点 | 先选中节点，再按 `Delete`。 |
| 撤销误操作 | 点击顶部撤销按钮，或按 `Ctrl + Z`。 |
| 找回看不见的结果 | 打开“历史 / 素材”，检查生成任务与素材库。 |

在文本框里滚轮可能滚动文字；在输入框中按删除键会编辑文字。要操作画布，先点击节点或空白处。

### 离开页面前看什么

1. 点击 **保存云端**。
2. 等待 **已保存 · v…**，不要停在“正在保存…”或“尚未保存到云端”。
3. 重要图片和视频另行下载。
4. 需要做另一个方案时，先保存，再到 **历史 / 素材 → 修订记录 → 复制已保存版本**。

系统会尝试自动保存，但成功状态才是确认依据。复制已保存版本只复制保存过的内容，未保存修改要先处理。

### 看到异常提示时怎么选

| 提示或现象 | 处理方法 |
| --- | --- |
| 发现未保存的本地草稿 | 想继续上次编辑，选“恢复草稿”；确定只用服务器版本，选“使用云端版本”。 |
| 出现“找回上次保存” | 先点它确认上次保存结果，再继续编辑或保存。 |
| 保存冲突 | 先用“保存本地工程”保留当前内容，再核对“读取云端版本”；读取会替换当前编辑。 |
| 生成提交后没有明确回执 | 进入生成任务，出现“找回提交”时先使用它；批次则用“找回批次”。 |
| 已有任务没有拿到结果 | 有“补拉结果”时先尝试补拉已有任务。 |
| 任务失败，想重新做 | “重试”会提交原版本任务，可能再次计费；如果改了提示词，要从当前节点重新生成。 |
| 媒体写入暂不可用 | 先保存文字编辑、查看已有素材；新媒体任务需等服务恢复。 |

“补拉结果”“重试结算”和“重试”用途不同。结果不确定时，先找回或补拉；仍无法确认再联系管理员。取消请求也不保证任务立即停止，已经受理的任务仍可能产生结果和费用。

## 7. 3D 导演台练习一：做一个简单推镜

目标：让摄影机从远处慢慢靠近一个人物，导出一条 3D 参考视频。

### 第一步：新建云工程

1. 点击系统左侧 **3D 导演台**。
2. 点击顶部 **云工程**。
3. 在 **创建新工程** 中输入“人物推镜练习”。
4. 点击 **新建空工程**。

**完成标志：** 顶部显示当前工程名称，不再只是“本地工程”。

如果已经摆好了场景，想保存现有内容，请用 **当前场景另存为**。

### 第二步：添加一个人物

1. 点击顶部 **添加角色**，选择一个预设角色。
2. 在左侧对象列表选中这个人物。
3. 先保留默认大小，把人物放在场景中容易看到的位置。
4. 如果要调整位置，选择顶部 **移动**；调整朝向用 **旋转**；调整大小用 **缩放**。

**完成标志：** 中间 3D 场景里能看到人物，左侧也有对应的对象名称。

第一次只放一个人物即可。道具和复杂模型可以等完成一个镜头后再加。

### 第三步：套用一个推镜

1. 点击顶部 **运镜**。
2. 找到 **一键镜头** 区域。
3. 在 **跟踪主体** 中选择刚才的人物。
4. 将 **轨迹范围** 先设为 `100%`。
5. 选择 **基础预设**，点击 **推镜**。
6. 将 **整段时长** 设为 `5 秒`，或先保留该预设默认时长。

**完成标志：** 镜头路线里出现轨迹点，预览按钮可以使用。

“推镜”是摄影机靠近人物；“拉镜”是摄影机远离人物。选择预设后，系统会帮你生成路线。

### 第四步：先看路线，再看拍出来的画面

1. 点击 **看路线**，观察摄影机是否穿进地面或人物身体。
2. 点击 **看成片**，检查人物是否在画面里、头部有没有被切掉。
3. 如果移动太快，增加整段时长；如果范围不合适，调整轨迹范围并重新预览。

**完成标志：** 在“看成片”里，人物保持在画面内，摄影机平稳靠近。

导演视角方便你从外面看场景；第一视角是活动摄影机拍到的画面。判断最终构图，以 **看成片** 为准。

### 第五步：保存并导出

1. 点击顶部云工程工具栏的 **保存**。
2. 确认显示 **正式版本已保存**。
3. 在运镜工作台点击 **导出**。
4. 画质先选 `720p`，帧率选 `30 FPS`。
5. 点击 **导出 MP4**。
6. 等录制与编码完成，浏览器会下载文件。

**完成标志：** 下载的 MP4 能播放刚才设计的推镜。

导出时保持页面打开，等待录制结束。这里得到的是不含音轨的 3D 运镜参考视频；真人或其他画风的 AI 视频，需要再走生成流程。

## 8. 3D 导演台练习二：自己决定镜头起点和终点

熟悉一键镜头后，再做这个练习。

1. 打开 **运镜**，点击 **开始掌镜**。
2. 再单击一次 3D 画面，让鼠标进入掌镜状态。
3. 用 `W / A / S / D` 移动摄影机，用 `E / Q` 上升或下降。
4. 移动鼠标调整朝向，在想要的起点按 `Enter` 记录镜头点。
5. 移到另一处，再按 `Enter` 记录终点。
6. 按 `Esc` 退出掌镜。
7. 检查路线里至少有两个点，点击 **看成片**。
8. 满意后保存，按上一节的方法导出。

如果不习惯键盘掌镜，也可以先调整导演视角，再点击 **添加当前视角**，换个位置后再添加一次。

### 三种“动”要分清

| 你要的效果 | 调哪里 |
| --- | --- |
| 人物站在原地挥手、做动作 | 选中角色，在右侧“动作”中选择可用动作。 |
| 人物从 A 点走到 B 点 | 选中角色，在右侧“路线”中设置人物路径。 |
| 摄影机从远处靠近人物 | 在“运镜”中设置镜头路线。 |

人物不动，摄影机也可以移动。第一次做推镜，无需先制作人物走路路线。

## 9. 把导演台参考用到项目片段

目标：用导演台控制人物站位和构图，再让 AI 生成项目图片或视频。

### 第一步：从项目片段进入

1. 打开项目的分镜片段编辑页。
2. 选择要处理的片段。
3. 点击该片段的 **3D 导演台** 入口。
4. 新建云工程；如果出现 **选择片段云工程**，选择对应工程。

从片段进入能关联目标片段，后续更容易把参考用到正确的位置。

### 第二步：摆位置，按需绑定角色

1. 在 3D 场景中摆好人物和道具，调整构图。
2. 如果项目已有角色图，点击 **角色绑定**。
3. 点击 **刷新角色候选**。
4. 为每个 3D 人物选择对应的角色造型参考图。
5. 点击 **保存**，发布绑定修改。

**完成标志：** 角色与造型绑定窗口显示选中的参考，保存成功。

角色绑定用于把角色图提供给后续 AI 生成，不会直接把眼前的 3D 模型变成那张角色图的外观。

### 第三步 A：需要一张构图参考图

1. 调整到想要的画面。
2. 点击 **导出并上传 → 导出垫图并上传**。
3. 等上传完成，在弹窗中检查实际导出的图片。
4. 按需要勾选 **附带角色参考图**。
5. 点击 **应用到片段图片**。
6. 要立即生成时，在窗口中选择图片模型与参数，填写提示词，再点 **生成图片**；也可以回片段页生成。

提示词可以参考：

```text
按照导演台垫图的人物站位、景别和构图生成画面。
画面左侧人物使用所附角色参考图中的造型。
场景改为午后庭院，暖色自然光，写实电影风格，无文字。
```

“应用到片段图片”表示参考已关联；“生成图片”才会提交 AI 图片任务。

### 第三步 B：需要一条运镜参考视频

1. 在 **运镜** 中做好路线，至少保留两个镜头点。
2. 点击 **看成片**，确认构图和运动。
3. 点击 **导出并上传 → 导出参考视频并上传**。
4. 等录制、上传完成，在弹窗里预览视频。
5. 点击 **加载视频模型**，选择目标模型。
6. 点击 **读取参考区**，核对目标片段的已有参考。
7. 按需要勾选 **附带角色参考图**。
8. 点击 **应用到片段视频**。
9. 返回片段编辑页，刷新参考与产物，再发起视频生成。

**完成标志：** 页面提示应用成功，目标片段能看到新加入的参考。应用参考不会自动生成最终视频。

能否使用参考视频及具体参数，以目标模型和应用时的校验提示为准。

## 10. 两个工具一起用：先定构图，再做视频

可以照这条路线完成一次练习：

1. 从项目片段打开 **3D 导演台**，摆好一个人物和机位。
2. **导出垫图并上传**，在弹窗中应用参考并生成图片。
3. 在项目片段的生成历史中查看满意的图片，下载到电脑。
4. 打开 **自由画布**，添加 **图片输入**，上传这张图片。
5. 添加 **AI 视频**，把图片连过去。
6. 输入人物动作与镜头运动提示词，选择支持参考图的模型并生成。
7. 在云端画布的生成任务中 **应用结果**，预览、下载并保存。

这一条路线传递的是图片参考。图片本身不包含导演台的运镜路线；需要使用导演台的视频运动参考时，请走第 9 节的“应用到片段视频”流程，并选择支持该输入的模型。

## 11. 导演台如何保存、换电脑和找回版本

### 每次收工前

1. 确认打开的是正确的云工程。
2. 如果导入过本地模型或动作，点击 **云素材**。
3. 模型有外部贴图、材质时，用 **选择依赖文件** 或 **选择依赖文件夹** 补齐文件。
4. 点击 **上传模型及依赖**，等待成功。
5. 点击顶部 **保存**。
6. 确认显示 **正式版本已保存**。

“草稿已保存，尚未发布”表示草稿已经暂存，还需要点击 **保存** 发布正式版本。只下载 MP4 不等于保存了可继续编辑的 3D 工程。

### 想保留两个方案

打开 **云工程**，输入新名称，使用 **当前场景另存为**。例如保留“人物推镜”和“人物拉镜”两个工程。

### 想回看生成时的场景

点击 **产物与历史** 查看历史修订。项目片段历史里有 **查看导演台来源** 时，也可以从那里打开对应来源版本。想在历史方案上继续修改，可使用 **复制当前修订继续编辑**。

### 保存迟迟没有明确结果

如果出现 **查询上次发布 / 原样重试发布**：先点 **查询上次发布** 核对。需要重试时按界面提示使用 **原样重试发布**，确认原发布请求的结果。

如果是版本冲突，先把要保留的当前场景另存，再核对云端草稿和正式版本。

## 12. 卡住时，按现象找答案

| 遇到的问题 | 先这样处理 |
| --- | --- |
| 双击没有创建节点 | 在画布空白处双击，不要双击已有节点或文本框。 |
| 图片节点有图，视频节点却没参考 | 检查连线方向和输入位置，确认当前模型允许参考图。 |
| 云端任务成功，节点还是空的 | 打开“生成任务”，点击该任务的“应用结果”。 |
| 生成按钮不可用 | 检查模型、必填参数、积分提示，以及是否有草稿、保存冲突或待找回提交。 |
| 某张图片显示不出来 | 先重试预览或刷新素材；不要急着删掉整个节点。 |
| 生成出来的角色不一致 | 使用同一张角色参考图，检查每个镜头是否真正带上参考，减少一次要求的变化。 |
| 画布节点多了很卡 | 点击顶部“性能模式”，先试普通模式。 |
| 导演台导入模型后看不到 | 在左侧选中对象，检查是否隐藏、位置是否太远、缩放是否过大或过小。 |
| 找不到角色绑定候选 | 确认从项目片段进入，项目已有可用角色图，再刷新角色候选。 |
| 绑定角色后 3D 人物外观没变 | 这是正常的；绑定影响后续 AI 参考，不替换 3D 模型。 |
| “导出 MP4”是灰色 | 检查活动摄影机的路线是否至少有两个点，可先套用一个基础预设。 |
| “开始掌镜”后鼠标没反应 | 再单击一次 3D 画面；按 Esc 可以退出掌镜。 |
| 导出视频的角度不对 | 先用“看成片”检查活动机位，确认摄影机没有进入模型内部或地面以下。 |
| MP4 导出没有马上结束 | 导出需要实时录制和编码，等待完成，保持页面打开。 |
| 浏览器提示不支持 MP4 导出 | 换用具备 MP4 录制支持的 Chrome 或 Edge 环境后重试。 |
| 应用到片段视频失败 | 检查上传是否完成、目标片段和模型是否正确，重新读取参考区后按提示处理。 |
| 换电脑后模型或贴图丢了 | 回原设备补齐“云素材”，上传模型及依赖，再保存正式版本。 |

仍无法解决时，把**正在做哪一步、页面报错原文、任务或工程名称**发给管理员，方便定位。

## 13. 下次使用，只看这张速查表

| 任务 | 操作顺序 |
| --- | --- |
| 生成图片 | 自由画布 → 双击 → AI 绘图 → 填提示词和模型 → 生成 → 应用结果 → 下载 → 保存云端 |
| 图片变视频 | 图片输入 → 连到 AI 视频 → 写动作 → 生成 → 应用结果 → 下载 → 保存云端 |
| 三个分镜 | 文字节点 → 连到智能分镜表 → 视频 → 脚本 → 检查参数 → 批量 → 预估费用 → 确认提交 → 应用结果 |
| 一键推镜 | 3D 导演台 → 云工程 → 添加角色 → 运镜 → 选主体 → 基础预设“推镜” → 看成片 → 保存 → 导出 MP4 |
| 项目图片参考 | 从片段进导演台 → 摆场景 → 保存 → 导出垫图并上传 → 应用到片段图片 → 生成图片 |
| 项目视频参考 | 做好运镜 → 保存 → 导出参考视频并上传 → 加载模型 → 读取参考区 → 应用到片段视频 → 回片段生成 |

完成一次练习后，你应该能找到：**一张已保存的云端画布、一份已保存的导演台云工程，以及下载到电脑上的图片或视频。**
