## 已实现

1. 画布与分析接口统一解析非 2xx 的 JSON 错误，保留 HTTP status、业务 code、data、响应头；缺失 submissionState 默认 unknown。网关 HTML、网络中断、413/422、错误码后缀不能单独证明未受理。
2. 生成、批次、文本、分析、扩展执行、工作流、上传、入库保留请求标识和正文。回执明确 notFound 才按原请求重放；notAccepted 才允许结束原待确认状态。成功请求保留恢复历史。创建、重命名、复制、恢复也保留原请求；保存使用 clientSaveId。
3. 请求记录按账号隔离，账号在异步鉴权或响应期间变化时拒绝继续；Web Locks 加 IndexedDB 后备租约限制同动作并发。删除清理编辑器缓存时保留请求恢复记录。
4. 素材独立加载。缺失或临时读取失败显示局部提示，保留 assetBindings、来源及历史素材 ID；重试预览只替换仍存在的原占位，不覆盖新编辑。analysisKeyframe 按 assetId 定位全部关键帧，不按 JSON Pointer 解析。
5. 下架模型的原绑定仍可保存；新媒体生成检查可用模型。服务错误保留节点、镜头和字段定位信息。任务补拉、结算、付费重试继续使用独立入口；未知费用不转成零。
6. 迟到保存/恢复回执检查 currentRevisionNo、deleted 及期间编辑变化；不以旧文档覆盖新编辑。复制使用新 canvasId 打开并重新取得副本完整文档，保留副本素材 ID。
7. retryAfterMs 按毫秒优先处理，支持 Retry-After 秒数/日期；传输层阻止等待期限内的重复网络请求。后台页面降低轮询频率；shouldPoll=false、媒体/文本 status=6 停止对应任务轮询。
8. mediaWriteReady=false 暂停新媒体写入，保留历史读取和文字编辑；缺失新增能力字段兼容旧后端。含新媒体步骤的工作流同样检查能力。
9. 管理员且 reviewReady=true 时显示核查入口：分页待核查、历史数组、证据登记、请求恢复。taskRef 使用列表业务 id；providerTaskId 仅媒体生成可填。resolved 仅登记证据，不在前端改变任务或余额；拒绝时保留表单内容。
