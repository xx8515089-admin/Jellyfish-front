# 自由画布列表最新媒体接入

接口契约见 [后端原始文档](canvas-list-cover.md)。原文“本仓库只包含后端及接入示例”指提供文档的后端仓库。

## 接入行为

- CanvasSummary → CanvasWorkspace → 项目大厅卡片透传五个封面字段；复用项目列表的图片／视频封面组件。
- 优先展示 coverUrl；地址为空或加载失败，且 coverAssetId 和 coverContentUrl 存在时，复用 StudioCanvases.content 携带 Authorization 读取媒体。
- 加载器使用当前后端地址及 canvasId、coverAssetId 构造契约中的 content 接口，不把登录信息发送到原始媒体域名，也不在查询参数中添加 token。
- 视频静音、行内播放，鼠标移入播放、移出暂停。私有媒体获取 Blob 后展示，组件销毁时取消请求并释放对象 URL；迟到响应不更新组件。
- 空封面、旧接口缺字段、未知媒体类型或读取失败时使用现有占位。封面标识或地址变化后重新加载。
- 保留现有云端分页拉取、本地旧画布合并、搜索和分页方式。窗口重新获得焦点时刷新列表取得最新封面，不追加画布详情或素材列表查询。

## 联调验收

检查公开图片／视频、私有图片／视频（coverUrl 为 null）、直链失败后鉴权回退、鉴权读取失败、全 null 与旧响应缺字段。翻页或离开列表时确认请求取消、对象 URL 释放；封面更新后可恢复展示。

私有视频的 Blob 回退会读取完整文件；当前实现未使用 Range 分段播放。
