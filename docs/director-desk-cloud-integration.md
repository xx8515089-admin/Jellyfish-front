# 导演台云工程接入

实现基于提供的 `director-desk-integration.md`。本项目直接挂载导演台 React 编辑器并使用 Shadow DOM 隔离样式，因此通过现有 store 与干净帧导出器连接，不需要独立 iframe 或新增部署服务。云工程模式不启用旧的外部消息桥接。

## 使用路径

1. 在片段编辑面板点击「3D 导演台」，目标片段会通过 `segmentId` 参数带入。也可以从独立导演台进入「云工程」。独立工程上传时需指定目标片段。
2. 新建、打开云工程，或将当前本地场景另存为云工程。云工程窗口支持搜索、分页与删除；打开后的地址携带 `cloudDeskId`，刷新会读取云端详情。
3. 在「角色绑定」中加载目标片段的角色候选，按人物 objectId 选择角色造型。点击「保存云工程」保存全量工程与设置。
4. 选择固定画幅后点击「导出垫图并上传」。流程为同状态导出快照和图片 → 保存快照 → 用保存响应的修订号上传文件。保存冲突停止后续上传，不自动重试覆盖。
5. 视频：选择模型并读取参考区，再追加垫图和角色图；回到片段编辑面板点击「刷新参考与产物」，核对真实参考编号后使用原视频生成流程。
6. 图片：在「使用已上传垫图」内选择图片模型、分辨率、质量和提示词，显式提交角色参考和站位参考。画幅与参考数量按返回的模型能力校验。角色位置描述需要用户确认。
7. 「产物与历史」支持按文件查看来源修订、再次使用垫图和设置工程封面。删除保留历史，已删除工程禁止保存和追加产物。

## 边界与联调

- 沿用 OpenAPI 的基础地址、登录头与 HTTP 错误处理，同时校验业务 code；上传由浏览器生成 multipart boundary。
- 出图设置包含画幅、显式可空 FOV 和真实播放时间点。导出锁定编辑器，检测场景修改，失败帧不上传。
- 工程修订与视频参考列表修订分别使用。参考列表冲突后需重新读取核对。
- 保存大小限制为 5 MiB。不可移植的浏览器素材显示警告，不提供自定义模型云同步。
- 附件引用的独立 API 文档和示例源码未随附件提供；当前请求基于正文列出的契约。生图 useOnly/doNotUse 按文字用途描述提交，需在实际后端联调确认完整 DTO。
- 后端 SQL 迁移与服务部署由后端环境负责，本次未运行迁移、启动服务或提交真实生成任务。

## 本地验证

`node --test scripts/test-director-cloud.mjs` 覆盖返回修订号绑定、冲突停止上传、导出变更检测、交互恢复、二进制文件、画幅校验、业务错误和大小限制。

`pnpm build` 执行 TypeScript 检查与生产构建。真实登录、云端权限/冲突、图像效果及生成历史回显仍需联调验收。
