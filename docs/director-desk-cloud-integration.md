# 导演台云工程接入

按新版 `director-desk-api.md` 第 11～17 节对接。编辑器直接挂载在当前 React 应用中，通过 store 获取原生工程，不需要另起 iframe 服务。附件中的后端交付说明不限制本次前端修改。

## 使用流程

1. 从片段进入导演台调用 `openForSegment`，首次创建、再次恢复；多工程显示选择器，明确提交所选工程，支持片段内分页。
2. 打开最新工程读取个人云草稿，由用户选择恢复、丢弃或取消。编辑后 1.5 秒防抖串行保存草稿，正式保存先提交最新快照再 `publishDraft`。工程、草稿、应用、视频参考版本独立传递。
3. 网络错误或冲突保留编辑器内容，停止自动重试；通过云草稿入口核对，或将当前场景另存为新工程。不会自动提升基础修订覆盖最新版本。历史修订通过复制继续编辑。
4. 角色面板读取 `bindingStatus`，可加载候选、替换和解除绑定；删除人物时清理绑定。副本的失效绑定提示及未知工程扩展字段继续保留。
5. 「上传本地模型及依赖」上传当前浏览器导入的主模型/动作及选择的依赖文件；目录选择保留相对路径。主模型使用原文件名，依赖目录必须与模型内部路径匹配。重复主文件名需先改名后导入。保存完整 manifest 后验证实际字节及依赖。
6. 恢复工程先验证当前修订的完整清单，再鉴权下载并复核 byteSize/SHA-256。每个云资源包使用独立加载器，仅映射包内资源，缺失依赖明确失败。内置资源继续沿用原加载方式。
7. 导出图片/参考视频期间锁定场景，正式发布对应快照后上传，并记录返回的正式修订。视频受浏览器 MP4 录制能力与 50 MiB 限制。上传成功后保留 fileId，应用失败可直接重试该产物。
8. 应用图片/视频使用 `applyCapture`，可选择不带角色参考。视频读取当前模型参考版本，由服务端原子追加并保留已有引用。应用不发起生成。
9. 片段页「导演台图片参考」重新读取已应用的 imageReferences，可配置模型和提示词生成。视频继续使用原有服务端参考列表。回到片段点击「刷新参考与产物」刷新视频参考。
10. 生成历史「查看导演台来源」读取真实生成记录 ID 对应的多个来源，打开准确修订；「产物与历史」提供修订分页与 `forkRevision` 副本入口，删除的工程仍能查看历史。

## 验证及限制

- `node --test scripts/test-director-cloud.mjs`：快照与上传修订一致、冲突阻断、导出变更、草稿/应用版本、素材哈希与依赖隔离。
- `pnpm run typecheck` / `pnpm build`：类型与生产构建验证。
- 沿用原始 Authorization token 与现有基础地址，multipart 由浏览器设置 boundary。
- 本次未启动服务、执行 SQL、调用真实模型。后端迁移、真实权限/CAS 并发、带纹理模型跨浏览器恢复和 WebGL 画面需在联调环境验收。
- 编辑器原有导入能力为 FBX / OBJ / GLB；没有增加独立 GLTF 文件导入器或图片转模型。OBJ 原加载器不处理 MTL 材质，复杂 FBX 材质也需要实际渲染确认。后端支持的文件格式不等于编辑器全部支持。
