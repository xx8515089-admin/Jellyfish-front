# 自由画布接口现状与缺口清单

> 2026-09-16：v2 已补充模型目录、业务资产关联、镜头及批次能力。最新接入情况见 [v2 接入说明](./free-canvas-cloud-integration-v2.md)；本文保留首版核查记录。

更新时间：2026-09-15

## 1. 结论与核查范围

自由画布首版的工程保存、素材管理、独立图片/视频生成和历史查询接口已完成前端接入。当前主要缺口是高级生成能力、业务资产直接引用、整图执行和协作能力。

本文依据后端文档 `tapnow-canvas-api-v1.md` 与当前前端代码整理。**“已接入”表示前端已有调用实现，不代表真实后端、存储及付费供应商已完成端到端验证。** 后端可能存在未写入文档的新接口，需要后端负责人确认。

接口缺口分为三类：

- **后端需要补充或扩展**：首版文档明确未提供，或现有接口不能覆盖目标行为。
- **前端尚未接入**：已有可复用接口，但画布尚未完成对应交互或数据绑定。
- **需要联调验证**：接口和前端实现已存在，仍需验证实际运行效果。

## 2. 已接入的接口

### 2.1 画布工程

以下路径统一以 `/api/v1/studio/canvases` 为前缀。

| 方法 | 路径 | 用途 |
| --- | --- | --- |
| GET | `/capabilities` | 检查存储初始化状态和首版能力 |
| POST | `/create` | 创建画布 |
| GET | `/list` | 查询画布列表 |
| GET | `/detail` | 读取当前或指定修订 |
| POST | `/save` | 保存节点、连线、视口及绑定 |
| POST | `/rename` | 重命名画布 |
| POST | `/delete` | 软删除画布 |
| GET | `/revisions` | 查询修订历史 |
| POST | `/restore` | 将历史修订恢复为新版本 |
| POST | `/copy` | 复制画布及引用素材 |

保存使用修订号校验和持久化请求标识；发生版本冲突时保留本地编辑，阻止自动覆盖。

### 2.2 画布素材

| 方法 | 路径 | 用途 |
| --- | --- | --- |
| POST | `/assets/upload` | 上传图片、音频、视频 |
| POST | `/assets/attach` | 关联本人其他画布的素材 |
| GET | `/assets/list` | 查询画布素材 |
| POST | `/assets/remove` | 移除当前素材关联，保留历史引用 |
| GET | `/assets/content` | 授权读取素材 |
| GET | `/assets/download` | 授权下载素材 |

**现有 attach 只接受画布素材的 sourceAssetId。业务资产库 ID、文件 fileId 不能直接代替画布 assetId。**

### 2.3 图片与视频生成

| 方法 | 路径 | 用途 |
| --- | --- | --- |
| POST | `/generations/costEstimate` | 生成前报价与余额校验 |
| POST | `/generations/create` | 提交生成 |
| GET | `/generations/detail` | 查询任务状态与结果 |
| GET | `/generations/list` | 查询画布生成历史 |
| GET | `/generations/submission` | 找回网络中断时的原提交 |
| POST | `/generations/cancel` | 请求取消 |
| POST | `/generations/retry` | 对符合条件的失败或取消任务重新提交 |
| POST | `/generations/sync` | 对支持恢复的任务补拉结果或核对结算 |

当前云端生成适配器只执行独立 `gen-image` 和 `gen-video` 节点，每次一个输出。生成结果进入历史，经用户应用后再保存到画布。

取消并不保证终止已受理的供应商任务；已经开始调用的任务仍可能产生结果与费用。

### 2.4 模型管理与角色资产

| 方法 | 路径 | 当前接入情况 |
| --- | --- | --- |
| GET | `/api/v1/system/suppliers/all` | 云端画布设置查询供应商 |
| GET | `/api/v1/system/suppliers/getModels` | 查询供应商下的模型，支持类型筛选与分页 |
| GET | `/api/v1/studio/models?type=2` | 图片节点可选模型目录 |
| GET | `/api/v1/studio/models?type=3` | 视频节点可选模型目录 |
| GET | `/api/v1/studio/assetLibrary/items` | 角色库查询，使用 assetType=1、status=1 |
| GET | `/api/v1/studio/files/content` | 读取角色资产图片；受保护文件携带登录鉴权 |

云端画布的接口模型设置采用左侧供应商、右侧模型列表。供应商与密钥在模型管理中维护；刷新配置同步更新画布可选模型。旧本地画布仍保留原接口配置界面。

角色库目前支持搜索、刷新、分页、图片预览和添加图片到画布。添加的是图片参考节点，保存时走画布素材上传流程，尚未直接关联完整角色资产。

## 3. 后端需要补充或扩展的能力

下表是能力需求，**不是已经确定的接口路径或正式协议**。后端可选择扩展现有接口或新增接口。

| 优先级 | 功能 | 首版缺口 | 建议后端提供的能力 |
| --- | --- | --- | --- |
| P1 | 业务资产直接引用 | attach 不接受角色、场景、道具库资产 | 按业务资产 ID 授权关联到画布，返回画布 assetId；明确去重、资产版本和失效规则 |
| P1 | 分镜与镜头级生成 | 无镜头级执行流程，前端也未完成 shotId 素材绑定保存 | 按镜头冻结输入、报价、生成、查询结果及应用所需素材信息 |
| P1 | 批量生成与多输出 | 仅单次单输出 | 批次标识、子任务列表、进度、多结果、部分失败、取消和独立计费状态 |
| P2 | 整图执行 | 没有按节点依赖自动运行的调度 | 工作流校验、执行计划、整图任务、节点状态、失败处理及暂停/取消语义 |
| P2 | 文本与分析节点 | 画布生成链路未覆盖文本润色、视频分析等 | 确认可复用的通用服务，补齐画布节点输入、执行记录、输出与计费关联 |
| P2 | 高级图片/视频生成 | 遮罩、首尾帧、MJ 专用入口等未开放；部分视频专用路由不支持 | 明确操作类型、媒体角色、模型能力、报价校验和结果结构 |
| P2 | 图片异常任务恢复 | 没有图片供应商任务 ID 恢复接口 | 对可恢复供应商补拉原任务；明确不可恢复状态，避免重复购买生成 |
| P2 | 人工核账 | 没有人工核账管理界面及明确处理流程 | 查询异常结算、审计记录、授权核账及处理结果；是否需新接口由后端确认 |
| P3 | 云端工程 ZIP 导入导出 | 无云端打包/导入任务接口 | 如需服务端打包，提供归档任务、下载、导入校验及素材重映射 |
| P3 | 分享与实时协作 | 首版不支持跨账号共享、实时协作 | 成员授权、访问撤销、并发编辑协议、变更同步及冲突处理 |
| P3 | 回收站 | 仅软删除，无恢复删除状态的接口 | 已删除列表、恢复及保留策略；与修订恢复区分 |

P1 表示建议优先建设，P2 表示后续扩展，P3 表示按产品需求安排。该顺序是建议，尚未作为排期确认。

### 3.1 业务资产关联建议

角色图片已经能通过“读取图片 → 添加画布 → 上传画布素材”使用，因此直接关联接口不是当前角色图片使用的前置条件。新增关联能力主要用于减少重复传输，并保留资产来源。

建议协议至少明确：

- 来源资产类型、业务资产 ID，以及使用封面还是指定素材/造型。
- 目标 canvasId、调用者访问权限和返回的画布 assetId。
- 同一资产重复关联的去重规则。
- 原资产更新或删除后，历史画布引用是否仍保持可用。
- 角色名称、造型、提示词等是否需要随快照保存。

不要直接放开任意 fileId 的关联而跳过来源权限校验。

### 3.2 生成能力与模型目录

模型管理中显示模型、模型处于启用状态，并不意味着画布支持该模型的全部入口。例如图片、视频、文本、首尾帧和专有路由有不同的执行要求。

建议确认现有 capabilities 是否能进一步提供“模型 + 操作”的可用能力信息，让前端隐藏或禁用尚未支持的操作。最终仍由 costEstimate 和 create 校验能力与价格。

## 4. 前端尚未完成，但不一定需要新增接口

| 功能 | 可复用资源 | 前端待办 |
| --- | --- | --- |
| 场景库、道具库 | 现有 assetLibrary/items 查询接口 | 按资产类型查询，补齐选择、预览及添加画布交互 |
| 完整角色信息使用 | 角色资产已有名称、造型、提示词等字段 | 明确用户选中角色后的行为，接入所需文本与图片；业务角色不等同于 Sora @角色身份 |
| 镜头级素材绑定 | 保存协议已有 shotId 字段 | 实现镜头位置解析、素材上传和绑定回写；当前适配器会阻止重存已有镜头绑定的版本 |
| 特殊模型入口展示 | 模型目录和能力信息 | 对照实际画布执行能力限制可选操作，避免显示即暗示可执行 |
| 本地工程导入云端 | 上传、create、save 已存在 | 完善导入校验、素材重映射及失败提示；不必为基础导入单独新增接口 |

## 5. 保存与历史问题的判断

### 5.1 本地保存与云端同步

现有基础接口能够覆盖保存需求。此前反复要求重新加载、保存状态不一致的问题，不能直接归因为缺少保存接口。

前端已调整：

- 找回保存、读取云端版本和修订恢复改为页面内操作。
- 替换前保留本地备份；同步期间的新编辑不被旧结果覆盖。
- 云端保存成功与浏览器本地记录清理失败分别提示。
- 本地 ZIP 导出遇到不可读素材时明确报错，避免静默导出不完整工程。

这些修改仍需真实服务联调确认。

### 5.2 生成历史

画布历史已有 `/generations/list`，不缺基础查询接口。云端任务应查询画布专属历史；通用任务列表按首版约定隐藏画布任务。

历史为空时，应检查 canvasId、登录账号、任务创建结果、请求错误，以及是否仍显示旧本地缓存面板。

## 6. 建议联调验收清单

不需要调用所有付费模型；先完成基础存储与查询，再对已确认可用的图片/视频模型进行受控验证。

1. 创建画布，添加节点和连线，保存后重新打开，内容与视口一致。
2. 上传角色图片，保存后重新打开，图片仍可读取且绑定正确。
3. 两个页面编辑同一画布，旧修订保存出现冲突且不覆盖新修订。
4. 保存或生成请求中断后，通过原请求标识找回，不重复创建或扣费。
5. 生成前报价，提交后查询任务，成功结果显示在画布历史并可应用。
6. 验证取消、允许重试的失败、结果不确定和补拉场景。
7. 修改模型管理配置后刷新画布，供应商展示和可选模型更新；核对普通账号权限。
8. 本地 ZIP 导出并重新导入，节点、连线及图片等素材完整。
9. 读取修订、恢复修订及复制画布，原版本和素材历史保持一致。

已运行的前端检查包括类型检查、生产构建及画布保存/生成适配器专项测试；真实数据库、文件存储和付费供应商链路尚未完成端到端验收。
