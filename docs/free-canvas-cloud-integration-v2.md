# 自由画布 v2 前端接入说明

更新日期：2026-09-16。依据 `tapnow-canvas-api-v2.md`，基础工程接口继续兼容首版。

## 部署前提

后端需完成 083、086 迁移并部署 v2。打开云端画布检查 `storageReady` 和 `apiVersion`；未就绪时显示错误。本次未执行迁移、启动服务或调用付费模型。

## 已接入

- **模型目录**：画布编辑使用 `/canvases/models`，设置界面也通过该目录按供应商分组，展示不可用原因、参考图限制、分辨率及恢复能力。不再调用 `system/suppliers` 管理接口。
- **业务资产**：原角色面板可切换角色、场景、道具；云端添加使用 `assets/attachLibrary`，通过 `assets/submission` 找回原关联。保存 `assetId/sourceLinkId`，素材列表展示来源快照。提示词不会自动追加。
- **上传回执**：上传携带持久化 `clientRequestId`；根据内容指纹复用请求记录，先查回执，明确未找到时才原标识重发。不再用文件名猜测 v2 上传结果。
- **镜头绑定**：保存和加载按稳定镜头 ID 处理 `settings.shots`；素材路径相对镜头，模型支持 `/model` 或 `/imageModel`、`/videoModel` 加 operation。不会用数组位置代替 shotId。
- **镜头生成**：单镜头图片、视频按钮直接进入云端保存、报价、确认和提交流程，不再要求前端填写供应商密钥。
- **批次任务**：左下角“批量生成”和分镜批量按钮打开任务选择窗口；每项 1–10 次、展开最多 50 项。保存后报价，确认预留上限再创建。网络异常可找回批次；失败项重试使用新标识并保留原批次。
- **任务恢复**：按 shouldPoll 轮询，按 actions 展示取消、重试、补拉和重试结算；展示预留与已结算积分，未知金额不显示为零。
- **历史筛选**：支持节点、镜头、批次和状态过滤；从生成历史发现 batchId，并读取批次汇总。批次取消不表示供应商已撤单。
- **结果应用**：用户确认后才应用；镜头结果按 nodeId/shotId 写入图片 output_url 或 video_url，读取期间的编辑变化会阻止覆盖。
- **错误位置**：保留服务端 nodeId、shotId、fieldPath，并在错误提示中展示。

## 交互与协议边界

- 批次是同一修订的独立任务集合，不执行节点依赖链，也不会自动把某个任务输出传给后续任务。
- maxTotalCredits 是提交时的预留上限，不是最终供应商费用封顶。
- v2 文档未列出完整批次报价响应结构；界面兼容常见总价/单价字段。无法识别总价时要求用户填写预留上限，后端仍负责最终报价、余额和预算校验。正式联调应核对真实返回字段。
- v2 没有批次列表接口；前端保留本机批次 ID，并从已加载的生成历史中发现其他批次。不会宣称已查询全部云端批次。
- 素材来源可以不同但共用文件。不同 sourceLinkId 的绑定分别保留，避免来源被文件去重覆盖。
- 旧本地画布仍保留本地配置和导入导出；本文新增云端能力不等于升级旧本地供应商执行链路。
- 整图调度、文本润色/视频分析、首尾帧、遮罩及专用 Wan/HappyHorse 路由仍不在 v2 范围。

本次验证是前端类型检查、构建及替身接口测试；真实数据库、账号权限、对象存储、批次报价字段和付费生成仍需服务端环境联调。


## 描述节点文本模型目录

角色描述、场景描述节点的云端文本模型选择器通过 `StudioModelsApi.getTextModels()` 请求 `GET /api/v1/studio/models?type=1`，展示供应商与模型名称；选中的后端模型 ID 单独保存在节点 `settings.textModelId`，不与旧本地 `chatModel` 配置混用。支持加载、失败重试、空目录和已选模型失效提示。

目录接入不代表文本执行已接入。现有画布 v2 契约仅提供图片、视频生成，未定义描述增强/过滤操作；云端这两个按钮暂不可用，并展示缺失说明。本地模式保留原 Chat 配置流程。后续后端需提供接收模型 ID、描述文本及 enhance/filter 操作的文本执行契约，前端才能完成调用闭环。
