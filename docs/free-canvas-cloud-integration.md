# 自由画布云端接入

> 2026-09-16：v2 已补充模型目录、业务资产关联、镜头及批次能力。最新接入情况见 [v2 接入说明](./free-canvas-cloud-integration-v2.md)；本文保留首版核查记录。

依据 `tapnow-canvas-api-v1.md`（2026-09-15）接入现有 Tapnow 编辑器。

## 已连接流程

- 列表、新建、重命名、删除使用 `/api/v1/studio/canvases`；列表分页读取后保持现有搜索和分页展示。
- 打开前检查 `storageReady`；使用现有登录原始 token 与语言请求头。
- 从详情载入节点、连接、视口和模型绑定；受保护素材通过鉴权请求生成 Blob URL。
- 编辑停止 1.5 秒后保存，也可点击左下角“保存云端”。保存请求带修订号与持久化请求标识，失败后暂停自动保存。
- 图片/音频/视频在保存时上传并生成 JSON Pointer 素材绑定；重复引用复用 assetId。供应商凭据不进入快照。上传结果不确定时查询素材列表，不自动重新上传。
- “云端历史 / 素材”提供任务分页、结果预览/应用、取消、重试、补拉、修订恢复、复制、素材关联/下载/移除。
- 生成按钮先保存快照，再报价和确认积分，最后提交。请求标识及原参数先落本地存储，网络异常可“找回提交”。状态 1/2 每 2.5 秒查询，状态 6 停止轮询。
- 成功输出只进入历史；点击“应用结果”并确认后才改变节点，之后保存新修订。加载输出期间节点再次变化会中止应用。
- 保存冲突读取最新修订，保留当前编辑并阻止继续覆盖；可先导出工程再打开最新云端版本。
- 原浏览器本地画布仍可打开。点击“复制本地画布到云端”迁移，原画布保留；无法唯一匹配的旧模型清空选择，需重新选择后端模型。

## 使用限制

首版不执行整图 DAG、镜头级任务、遮罩、首尾帧、多输出、业务素材库或自定义 HTTP 模板；后端报价负责模型能力及价格的最终校验。已有镜头级素材绑定的版本暂不允许从该适配器重新保存，避免丢失绑定。

“导出本地快照”只导出 JSON；包含媒体时优先使用编辑器原有工程导出。草稿会备份本地 Blob 内容，浏览器存储空间不足时会提示及时云端保存或导出。

## 验证

- `pnpm run typecheck`
- `pnpm exec vite build`
- `node --test scripts/test-canvas-cloud.mjs`

没有自动启动服务、执行数据库迁移或调用真实付费模型。真实后端联调需用户已运行的服务、已初始化的画布存储和可用图片/视频模型。

## 复查修复（2026-09-15）

- HTTP 422 等明确失败后清除相应待确认请求，允许修改参数再保存；网络结果不确定时仍保留原标识重放。
- 草稿记录基础修订号；跨修订草稿可恢复到本地，但禁止自动覆盖新云端版本。
- 找回上次保存前先备份当前编辑，避免刷新丢失新增内容。
- 轮询只更新当前任务页已有条目，忽略过期分页请求，避免任务串页。
- 保留 `img_` 等形式的节点原始 ID；局域网 HTTP 环境兼容没有 `crypto.randomUUID` 的浏览器。
- 云端列表失败时保留旧本地画布列表。
- 专项回归已扩展至 20 项；仍未执行真实后端或付费供应商联调。

## 保存流程修复

- 保存找回、读取云端版本及修订恢复改为页面内操作，不再强制刷新。
- 替换前保存本地冲突备份，可通过“恢复本地备份”找回。
- 同步请求期间新增的编辑不会被旧结果覆盖。
- 云端保存成功后，本地记录清理异常单独提示，不再误报云端失败。
- 本地 ZIP 读取失败明确报错，素材使用独立文件名；空画布导入会清空旧节点及连线。
