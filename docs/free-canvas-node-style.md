# 自由画布节点样式规范

## 公共规范

所有节点由 `canvas-node` 容器提供主题变量，深色、浅色和护眼主题共用布局。

- 标题栏：约 42px 高度，12px 标题，14px 水平边距。
- 内容区：14px 内边距，12px 分区间距。
- 表单：11px 标签、12px 输入文字，7px 圆角，明确的聚焦边框。
- 操作：常规按钮约 32–34px，辅助按钮约 28px；图标按钮和连线端口保持自己的尺寸。
- 结构：外框 12px 圆角，分区 8px 圆角；状态颜色保持语义。
- 新建节点使用更新的默认尺寸，不修改已有工程中的节点尺寸与坐标。

## 各类布局

| 节点 | 布局规则 |
| --- | --- |
| 图片、视频输入 | 统一素材空状态，媒体本身保留显示比例及交互 |
| AI 图片、视频生成 | 标题、提示词、辅助区、参数工具栏；窄节点模型选择独占一行 |
| 角色、场景描述 | 模式切换、提示词、辅助动作、设置、参考图，使用公共主题变量 |
| 角色/场景图片与视频生成 | 表单字段统一，内容滚动，底部操作区单独呈现 |
| 小说、文本、提取、创建角色/场景、本地保存、视频分析 | 共用表单、标题和操作样式 |
| 分镜 | 使用公共颜色与字号，保留紧凑表格结构和横向滚动 |
| 预览、图像对比 | 共用外框和表面颜色，保留媒体视口与对比控件 |

## 维护位置

- `src/pages/canvas/TapnowStudio/components/CanvasNodes.css`：公共规范。
- `DescriptionNode.css`：描述节点专属布局，主题变量引用公共规范。
- `GenerationNodeContent.jsx`：生成节点的提示词、辅助库与参数栏。
- `StoryboardNodeContent.jsx`：分镜表的专属布局。

新增节点应使用公共变量，避免单独定义另一套背景、输入框和按钮颜色。不要把统一表单尺寸应用到连线端口、遮罩、缩放手柄或媒体坐标。
