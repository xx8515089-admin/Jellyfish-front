# Reelmax 自由画布用户手册

> 适用对象：第一次接触节点画布、不懂工作流、只想尽快生成图片或视频的普通用户。
> 本手册按 Reelmax 当前自由画布界面和实际功能编写。

## 一句话说明

自由画布是一张可以自由摆放“功能方块”的创作桌面。每个方块叫作**节点**，节点之间的线表示素材或文字从上一步流向下一步。

生成视频最常用的两条路线是：

1. **快速生成一条视频**：`AI 视频` 节点 -> 填提示词 -> 选择模型和参数 -> 生成。
2. **批量生成多镜头视频**：`文字节点/小说输入` -> `智能分镜表` -> 切换到视频模式 -> 批量生成。

如果你现在完全不知道从哪里开始，直接照着下一节操作。先做出第一条视频，再看后面的完整说明。

## 5 分钟生成第一条视频

### 第 1 步：新建并打开画布

1. 在 Reelmax 左侧菜单点击 **自由画布**。
2. 点击列表中的 **新建画布** 卡片。
3. 系统会创建一个“未命名画布”并自动进入。
4. 打开后，中间带点阵的黑色区域就是画布。

画布顶部显示 **自动保存**，表示节点、连线和画布位置会保存到当前画布对应的本地工作区。

> 重要：自动保存主要依赖当前浏览器的本地数据。不要随意清理浏览器站点数据，也不要把“换浏览器或换电脑”当成自动同步。重要项目建议额外使用左侧的“保存项目”导出备份。

### 第 2 步：添加 AI 视频节点

1. 在画布空白处**双击鼠标左键**。
2. 在弹出的节点菜单中点击 **AI 视频**。
3. 画布上会出现一个视频生成节点。

刚进入空画布时，中间也会显示“双击画布，自由生成节点”的提示。

### 第 3 步：输入视频提示词

在 AI 视频节点的大文本框中输入你想看到的画面和运动。例如：

```text
电影感中景，一名穿黑色风衣的年轻女性站在雨夜霓虹街道上，
她缓慢抬头看向镜头，风吹动头发和衣摆，镜头平稳向前推进，
地面有雨水倒影，蓝紫色霓虹光，人物动作自然，画面稳定，无文字。
```

写视频提示词时，至少说清楚四件事：

- **主体**：谁或什么出现在画面中。
- **动作**：主体做什么。
- **镜头**：推进、拉远、环绕、横移、固定等。
- **环境和风格**：时间、地点、光线、画面质感。

### 第 4 步：选择模型和参数

在节点底部依次检查：

- **模型**：选择一个已经启用的视频模型。
- **画面比例**：如 `16:9`、`9:16`。横屏用 `16:9`，竖屏短视频用 `9:16`。
- **分辨率**：第一次测试优先选较低或常规分辨率，生成更快。
- **时长**：第一次建议选模型允许的较短时长。
- **HD / 首尾帧**：只有支持这些能力的模型才会显示。

不同模型支持的比例、分辨率、时长和参考图数量不一样。界面只会显示当前模型可用的选项，不需要强行寻找本模型不支持的参数。

### 第 5 步：点击生成

1. 点击节点右下角的三角形 **生成** 按钮。
2. 节点进入生成状态后不要连续反复点击。
3. 等待任务完成，结果会显示在节点中，并进入左侧的 **生成历史**。

如果系统提示“请先在 API 设置中配置 Key”，请先看本手册的“模型与 API 设置”章节。

### 第 6 步：预览并下载

1. 在生成节点或生成历史中打开视频结果进行预览。
2. 确认画面、动作和时长符合要求。
3. 下载单条结果，或者在生成历史中勾选多条后批量下载。

到这里，你已经完成了一条视频。

> 自由画布的 AI 视频节点通常一次生成一条视频片段；智能分镜表可以一次生成多条镜头片段。多条片段不会自动变成剪辑完成的整片，需要下载后在剪辑工具中按顺序组合。

## 生成视频的三种常用方法

### 方法一：纯文字生成视频

适合没有参考图片、希望 AI 从零生成画面的情况。

操作路径：

`AI 视频 -> 输入提示词 -> 选择模型/比例/分辨率/时长 -> 生成`

建议第一次这样设置：

- 只生成 1 条。
- 使用短时长。
- 使用常规分辨率。
- 提示词只描述一个主体和一个主要动作。
- 镜头运动不要同时写“推进、环绕、快速摇镜、升降”等多个互相争抢的动作。

适合的提示词结构：

```text
【景别】中景
【主体】一名穿白色宇航服的女孩站在荒凉月面
【动作】她缓慢转身并抬头望向远处地球
【镜头】镜头从侧后方平稳向前推进
【环境】月尘轻微飘动，远处可见地球，冷色光
【质量要求】电影感，动作自然，画面稳定，无字幕，无水印
```

### 方法二：图片生成视频

适合已有角色图、场景图、产品图，希望让静态图片动起来的情况。

#### 添加参考图片

1. 在画布空白处双击。
2. 选择 **图片输入**。
3. 在图片输入节点中选择本地图片；也可以尝试直接把图片文件拖入画布。
4. 再双击空白处，添加 **AI 视频** 节点。

#### 连接图片和视频节点

1. 找到图片节点边缘的小圆形连接点。
2. 从图片节点的输出连接点按住鼠标拖动。
3. 把线拖到 AI 视频节点的输入连接点后松开。
4. 看到两个节点之间出现连线，表示参考图已经传给视频节点。

连线方向可以理解为：

`参考图片（上游） -> AI 视频（下游）`

#### 填写运动提示词

图生视频时，不需要把图片已有内容从头描述一遍，重点写“接下来怎么动”：

```text
人物保持原有造型和面部特征，缓慢转头看向镜头，轻轻眨眼，
头发被微风吹动，镜头缓慢向前推进，背景光影自然变化，
动作幅度小，画面稳定，不改变服装，不增加其他人物。
```

#### 使用首尾帧

当所选视频模型支持首尾帧时，节点会显示 **首尾帧** 开关。

1. 打开 **首尾帧**。
2. 准备两张图片：第一张作为开始画面，第二张作为结束画面。
3. 按节点中的“首帧”和“尾帧”位置提供图片。
4. 提示词描述从第一张画面到第二张画面的过程。

首尾帧适合：

- 人物从站立变为转身。
- 产品从正面过渡到侧面。
- 白天场景过渡到夜晚场景。
- 镜头从远景推进到近景。

不要使用差异过大的两张图，否则容易出现人物变形、场景跳变或中间帧混乱。

### 方法三：智能分镜批量生成视频

适合剧本、短片、广告、多镜头故事等需要一次生成多条视频的情况。

完整路径：

`文字节点/小说输入 -> 智能分镜表 -> 视频模式 -> 设置每个镜头 -> 批量生成 -> 批量下载`

#### 第 1 步：准备分镜文字

最简单的方法是在 **文字节点** 中按行写镜头：

```text
#1 雨夜城市远景，霓虹灯倒映在湿润路面，镜头缓慢向前移动。
#2 女主角站在街边抬头看雨，头发和衣摆被风吹动，中景推进。
#3 女主角转身走入巷子，镜头从背后平稳跟随。
#4 她在巷口停下回头，近景，背景霓虹虚化。
```

系统可以识别的常见写法包括：

- `#1 镜头内容`
- `【1】镜头内容`
- `1. 镜头内容`
- 每行一条镜头内容

长篇内容也可以使用 **小说输入**，再结合角色和场景提取节点进行整理。第一次使用建议先从 3 至 5 个短镜头开始。

#### 第 2 步：添加智能分镜表

1. 双击画布空白处。
2. 选择 **智能分镜表**。
3. 把文字节点连接到智能分镜表。
4. 点击分镜表顶部的 **脚本**。
5. 如果已经连接文字节点，系统会直接拆分上游文字；没有连接文字节点时会展开手动输入区。

#### 第 3 步：切换到视频模式

在智能分镜表顶部找到 **图片 / 视频** 切换，点击 **视频**。

切换后，系统会为镜头使用可用的视频模型，并显示视频相关参数。

#### 第 4 步：逐条检查镜头

每个镜头至少检查：

- 提示词是否只描述一个清楚的画面。
- 模型是否是视频模型。
- 比例是否一致。
- 分辨率是否一致。
- 时长是否合理。
- 参考图是否正确。

分镜表支持 **卡片视图** 和 **表格视图**。镜头少时卡片视图更直观，镜头多时表格视图更方便集中检查。

#### 第 5 步：设置批量并发

分镜表顶部的数字框用于设置并发数量：

- `1`：一次只生成一个镜头，最稳妥。
- `2` 或 `3`：同时生成少量镜头，速度和稳定性较均衡。
- `0`：全部并发，不限制数量。

第一次使用建议设置为 `1` 或 `2`。不要一上来就使用 `0`，否则可能同时提交大量任务，造成接口限流、余额快速消耗或浏览器卡顿。

#### 第 6 步：批量生成

1. 点击分镜表顶部的 **批量**。
2. 待生成镜头会进入队列。
3. 已完成或被锁定的镜头不会重复生成。
4. 如果只想重做部分镜头，先取消这些镜头的锁定，再重新批量生成。

#### 第 7 步：下载结果

点击分镜表顶部的批量下载按钮，可以下载全部结果或选中的结果。下载后按照镜头编号放入剪辑软件，即可组合成完整视频。

## 看懂自由画布界面

### 顶部外层栏

- **画布列表**：返回自由画布列表。
- **画布名称**：当前画布名称。
- **自动保存**：当前画布会自动保存本地状态。

### Reelmax Canvas 顶部工具栏

- **Reelmax Canvas**：自由画布工作区。
- **画布名称**：点击可修改内部项目名称。
- **加号**：新建空项目，会清空当前内部内容，使用前先确认已备份。
- **性能模式**：在关闭、普通和极致模式之间切换。节点很多或拖动卡顿时可开启。
- **下载**：批量下载当前选中的图片或视频节点。
- **明暗主题**：切换画布显示主题。
- **中文/英文**：切换画布语言。
- **撤销 / 重做**：撤销或恢复节点操作。
- **清空**：清空当前画布内容，属于高风险操作。
- **API 设置**：配置生成模型和接口信息。

### 左侧工具栏

左侧图标用于打开不同面板，常用的有：

- **生成历史**：查看正在生成、已完成和失败的任务。
- **角色库**：管理可复用的角色素材。
- **AI 对话**：在画布内部打开辅助对话。
- **保存项目**：导出当前项目备份。
- **加载项目**：打开以前保存的完整项目。
- **导入工作流**：导入节点和连线工作流。

鼠标停在图标上会显示功能名称。第一次使用找不到按钮时，先把鼠标停留一秒看提示。

### 中间画布

中间区域用于：

- 双击创建节点。
- 拖动节点改变位置。
- 连接节点传递素材。
- 拖动画布查看其他区域。
- 使用滚轮缩放。
- 框选和多选节点。

### 生成历史面板

生成历史用于查看所有图片和视频任务：

- 生成中。
- 已完成。
- 失败。
- 本次生成结果。
- 历史生成结果。

历史面板顶部还提供：

- 性能模式。
- 本地缓存设置。
- 全局队列。
- 全选/取消全选。
- 批量管理。
- 批量下载。

## 节点是什么

把节点理解成“一个步骤”即可，不需要学习编程。

### 输入类节点

| 节点 | 什么时候用 | 输出什么 |
| --- | --- | --- |
| 图片输入 | 导入角色图、场景图、产品图 | 图片素材 |
| 文字节点 | 输入短提示词或分镜文本 | 文字内容 |
| 小说输入 | 输入长篇剧本或小说 | 长文本素材 |
| 视频输入 / 关键帧整理 | 导入现有视频并整理关键帧 | 视频和关键帧 |

### 分析类节点

| 节点 | 什么时候用 | 输出什么 |
| --- | --- | --- |
| 提取角色和场景 | 从剧本中识别人和地点 | 角色、场景候选 |
| 角色描述 | 维护人物外观和身份 | 稳定的角色描述 |
| 场景描述 | 维护地点、光线和氛围 | 稳定的场景描述 |
| 视频拆解 / 提示词反推 | 分析已有视频 | 关键帧、镜头或提示词参考 |

### 生成类节点

| 节点 | 什么时候用 | 输出什么 |
| --- | --- | --- |
| AI 绘图 | 通用文生图、图生图 | 图片 |
| AI 视频 | 通用文生视频、图生视频 | 视频片段 |
| 生成角色图片 | 根据角色描述生成人物图 | 角色图片 |
| 生成场景图片 | 根据场景描述生成环境图 | 场景图片 |
| 生成角色视频 | 让角色素材动起来 | 角色视频 |
| 生成场景视频 | 生成场景动态片段 | 场景视频 |

### 组织和辅助节点

| 节点 | 什么时候用 | 作用 |
| --- | --- | --- |
| 智能分镜表 | 多镜头批量生产 | 管理镜头、参数、队列和下载 |
| 创建角色 | 把人物保存为可复用角色 | 形成角色资产 |
| 创建场景 | 把环境保存为可复用场景 | 形成场景资产 |
| 图像对比 | 比较两张图片 | 选择更合适的结果 |
| 预览窗口 | 集中查看输出 | 预览图片或视频 |
| 保存到本地 | 配合本地缓存 | 保存生成素材到指定目录 |

第一次使用只需要记住三个节点：**图片输入、AI 视频、智能分镜表**。

## 节点和连线怎么操作

### 创建节点

- 在空白画布上双击。
- 从菜单中选择需要的节点。

### 移动节点

- 按住节点标题或非输入区域拖动。
- 不要从文本框、按钮或下拉框上开始拖动，否则会操作控件本身。

### 移动画布

- 在空白区域按住鼠标左键拖动。

### 缩放画布

- 鼠标放在画布空白区域，滚动滚轮。
- 鼠标放在可滚动的分镜表、文本框或面板上时，滚轮优先滚动该区域。

### 连接节点

- 从上游节点边缘的小圆点拖到下游节点的输入圆点。
- 连接成功后会出现一条线。
- 同一个专用输入位置重新连接时，新连接可能替换旧连接。

### 选择和多选

- 单击节点：选择一个节点。
- `Ctrl` / `Command` + 单击：追加选择多个节点。
- `Ctrl` / `Command` + 在空白处拖动：框选多个节点。

### 删除节点

1. 先选中一个或多个节点。
2. 按键盘 `Delete`。

在输入框中编辑文字时，`Delete` 只会删除文字，不会删除节点。

### 撤销和重做

- `Ctrl/Command + Z`：撤销。
- 顶部也有撤销和重做按钮。

### 复制和粘贴

- 选中节点后使用 `Ctrl/Command + C`。
- 使用 `Ctrl/Command + V` 粘贴。

复制多个节点时，节点之间的内部连线也会一起保留。

## 视频参数怎么选

### 画面比例

| 用途 | 推荐比例 |
| --- | --- |
| 电脑、电视、横屏视频 | `16:9` |
| 抖音、短视频、手机竖屏 | `9:16` |
| 社交平台方形内容 | `1:1` |
| 电影宽银幕感 | `21:9`，前提是模型支持 |

同一个项目的镜头尽量统一比例，否则剪辑时会出现黑边或裁切。

### 分辨率

- 测试阶段：选择较低或常规分辨率。
- 最终阶段：在画面、动作和提示词确定后再提高分辨率。
- 分辨率越高，通常生成越慢、消耗越高。

### 时长

- 单一小动作：短时长。
- 明确的镜头运动或动作过程：中等时长。
- 不要为了“内容更多”盲目拉长时长，AI 可能在后半段出现漂移或变形。

### 首尾帧

- 需要控制开始和结束画面时使用。
- 两张图的主体、服装、场景和构图越接近，过渡越稳定。
- 模型不支持时不会显示该选项。

### HD

- 只有支持 HD 的模型才显示。
- 建议先关闭 HD 测试，效果确认后再开启生成最终版本。

## 怎样写出更容易成功的视频提示词

### 推荐公式

```text
主体 + 主体动作 + 镜头运动 + 场景变化 + 光线风格 + 稳定性要求
```

### 好例子

```text
一辆银色概念跑车停在雨夜城市街道，车灯逐渐亮起，车身表面有雨水滑落，
镜头从左前方缓慢横移到正前方，地面反射蓝色和红色霓虹光，
电影广告质感，运动平稳，车身结构保持一致，无文字，无水印。
```

### 容易失败的例子

```text
一个人跑步，然后坐飞机，再来到海边，变成机器人，镜头快速旋转，
同时推进拉远，画面超级震撼，什么都有。
```

失败原因：一个短片段里塞入太多地点、动作和互相冲突的镜头要求。

### 图生视频提示词重点

- 少写静态外观，重点写动作和镜头。
- 明确“保持人物身份、服装和背景一致”。
- 动作幅度由小到大测试。
- 先让人物眨眼、转头、走一步，再尝试奔跑、打斗等复杂动作。

## 队列：管线和并行是什么意思

打开左侧 **生成历史**，再打开 **全局队列**，可以看到两种模式。

### 管线

任务按顺序处理，前一个完成后再处理后一个。

适合：

- 接口有并发限制。
- 余额有限，希望更可控。
- 镜头存在前后依赖。
- 第一次批量生成。

### 并行

多个任务可以同时处理。

适合：

- 模型和接口明确支持并发。
- 多个镜头互不依赖。
- 需要更快完成批量任务。

并行不一定永远更快。如果接口限流、电脑性能不足或一次提交过多，反而会出现失败、卡顿或等待时间变长。

### 任务卡住怎么办

1. 先查看任务是否仍显示“生成中”。
2. 等待一段合理时间，不要连续重复提交。
3. 在全局队列中确认运行数和排队数。
4. 必要时终止卡住的任务，再对失败镜头重新生成。
5. 如果多个任务同时失败，把并发改为 `1`。

## 生成历史、预览和下载

### 查看结果

打开左侧 **生成历史**，可以查看：

- 当前任务状态。
- 图片和视频缩略图。
- 已完成、失败或仍在运行的任务。
- 本次生成和以前生成的资产。

### 批量选择

1. 在生成历史中勾选需要的结果。
2. 点击批量下载按钮。
3. 没有手动选择时，可以选择下载“本次生成”或“全部资产”。

### 顶部下载按钮

顶部的 **下载** 用于下载画布中当前选中的图片或视频节点：

1. 先选中一个或多个包含结果的节点。
2. 点击顶部 **下载**。

### 本地缓存

生成历史的文件夹按钮用于本地缓存设置，可以：

- 设置图片和视频保存路径。
- 启用本地缓存。
- 选择是否重新下载缓存。
- 刷新缓存并重建缩略图。

如果只是第一次生成视频，不需要先配置本地缓存，直接使用浏览器下载即可。

## 自动保存、手动备份和恢复

### 自动保存保存什么

自动保存通常包括：

- 节点。
- 连线。
- 节点参数。
- 画布视图位置。
- 当前画布对应的生成历史和本地数据。

### 自动保存不等于云端备份

以下操作可能导致本地数据无法找回：

- 清理浏览器缓存和站点数据。
- 使用无痕模式。
- 更换浏览器或电脑。
- 删除画布。
- 点击新建空项目或清空，却没有提前导出。

### 手动备份

1. 点击左侧 **保存项目**。
2. 选择保存位置。
3. 保留导出的项目文件。

恢复时点击 **加载项目**，选择以前保存的项目文件。

### 工作流和完整项目的区别

- **保存项目 / 加载项目**：用于备份和恢复较完整的当前工作区。
- **导入工作流**：更适合导入节点结构和连线模板。

重要项目建议每天至少导出一次完整项目备份。

## 模型与 API 设置

### 什么时候需要配置

出现以下情况时需要检查 API 设置：

- 模型列表为空。
- 生成按钮点击后提示缺少 Key。
- 所有视频模型都不可用。
- 请求立即失败并提示接口地址、网络或鉴权错误。

### 检查步骤

1. 点击画布右上角 **API 设置**。
2. 确认至少有一个视频模型已启用。
3. 确认供应商、模型、请求地址和 API Key 已由管理员正确配置。
4. 回到 AI 视频节点，重新选择可用模型。
5. 先用一条短提示词测试。

如果模型由后台模型库统一下发，普通用户不需要自行填写接口，只需要选择管理员已经启用的模型。

> API Key 属于敏感信息，不要截图发送到群聊，也不要写入提示词或项目名称。

## 常见问题排查

### 1. 双击画布没有弹出节点菜单

- 确认双击的是空白区域，不是节点、文本框或侧边栏。
- 关闭覆盖在画布上的弹窗或下拉菜单。
- 把画布缩放恢复到容易操作的范围后重试。

### 2. 生成按钮点了没反应

按顺序检查：

1. 是否输入了提示词，或连接了参考图片。
2. 是否选择了可用模型。
3. 是否配置了 API Key。
4. 是否已有同一任务正在生成。
5. 生成历史或全局队列是否显示排队。

### 3. 提示“请输入提示词或连接参考图片”

AI 视频节点至少需要以下之一：

- 一段视频提示词。
- 一张已连接的参考图片。

最稳妥的做法是两者都提供。

### 4. 图片连接了但视频没有参考图片效果

- 检查连线是否从图片节点指向 AI 视频节点。
- 检查模型是否支持图生视频。
- 检查参考图数量是否超过模型限制。
- 如果开启首尾帧，确认首帧和尾帧位置没有放反。

### 5. 模型、比例、分辨率或时长选项很少

这是模型能力限制，不是界面丢失。更换模型后，可用参数会随模型变化。

### 6. 生成一直转圈或长时间停在生成中

- 到生成历史和全局队列查看真实状态。
- 把并发改为 `1`。
- 检查网络和接口余额。
- 终止确认已卡住的任务，再重新生成。
- 不要在等待时连续点击生成，否则可能重复扣费或增加排队任务。

### 7. 批量生成只生成了一部分镜头

- 检查剩余镜头是否被锁定。
- 检查镜头是否已经处于“生成中”。
- 检查每个镜头是否都选择了视频模型。
- 查看失败镜头的错误提示并单独重试。

### 8. 生成结果不连贯

- 所有镜头统一角色描述、服装、场景和画面比例。
- 为同一角色使用同一张参考图或角色资产。
- 每个镜头只描述一个主要动作。
- 相邻镜头使用相近的光线、色调和时间。
- 先生成图片关键帧，确认角色和场景一致后再图生视频。

### 9. 生成结果变形或动作混乱

- 减少动作数量和动作幅度。
- 缩短视频时长。
- 使用更清楚、主体完整的参考图。
- 避免手部遮挡、多人拥挤和复杂快速运动。
- 去掉互相冲突的镜头指令。

### 10. 下载按钮不可用或没有文件

- 确认任务已经完成。
- 确认选中的是包含生成结果的节点，不是输入节点。
- 在生成历史中直接选择已完成结果后下载。
- 检查浏览器是否阻止了多个文件下载。
- 批量下载失败时，先测试单条下载。

### 11. 刷新后节点不见了

- 确认打开的是同一个画布，不是另一个未命名画布。
- 检查是否使用了无痕模式或清理过浏览器数据。
- 尝试使用 **加载项目** 打开最近的手动备份。

### 12. 节点很多以后拖动卡顿

- 开启顶部 **性能模式**。
- 关闭暂时不用的生成历史、分镜大面板和预览窗口。
- 把超大型工作流拆成多个画布。
- 避免同时播放多个视频预览。
- 降低批量并发数量。

## 新手最稳妥的完整视频工作流

如果要做一个有 4 个镜头的短视频，推荐按下面顺序：

1. 先在文字节点写 4 条简短分镜。
2. 创建智能分镜表并连接文字节点。
3. 点击脚本拆分镜头。
4. 先切到图片模式，为每个镜头生成关键帧。
5. 检查角色、服装、场景和色调是否一致。
6. 锁定满意的关键帧。
7. 切换到视频模式。
8. 把关键帧作为各镜头的视频参考图。
9. 所有镜头统一比例和基础参数。
10. 并发设置为 `1` 或 `2`。
11. 批量生成视频。
12. 逐条预览，不满意的镜头单独重做。
13. 批量下载最终镜头。
14. 在剪辑软件中按镜头编号排列，添加转场、配音、音乐和字幕。

这条路线比直接让 AI 从纯文字一次生成所有视频更慢，但角色一致性和镜头可控性通常更好。

## 一页速查

### 只生成一条视频

`双击空白处 -> AI 视频 -> 输入提示词 -> 选模型/比例/分辨率/时长 -> 点击三角生成 -> 历史中预览和下载`

### 用图片生成视频

`图片输入 -> 导入图片 -> 连接 AI 视频 -> 写动作和镜头 -> 生成`

### 批量生成多镜头

`文字节点 -> 智能分镜表 -> 脚本 -> 视频模式 -> 检查每个镜头 -> 设置并发 -> 批量 -> 批量下载`

### 常用操作

| 操作 | 方法 |
| --- | --- |
| 新建节点 | 双击画布空白处 |
| 移动画布 | 空白处按住左键拖动 |
| 缩放画布 | 鼠标滚轮 |
| 多选节点 | `Ctrl/Command + 单击` |
| 框选节点 | `Ctrl/Command + 空白处拖动` |
| 删除节点 | 选中后按 `Delete` |
| 撤销 | `Ctrl/Command + Z` |
| 复制 | `Ctrl/Command + C` |
| 粘贴 | `Ctrl/Command + V` |

### 第一次使用的推荐原则

- 先短后长。
- 先低分辨率测试，再生成最终版本。
- 先一个镜头成功，再批量。
- 先并发 `1`，稳定后再提高。
- 先生成关键帧，再做图生视频。
- 重要画布除了自动保存，还要手动导出备份。
