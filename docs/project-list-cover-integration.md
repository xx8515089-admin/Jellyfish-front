# 项目列表最新媒体接入

接口契约见 [后端提供的原始文档](project-list-cover.md)。原文中的“本仓库只包含后端”指提供文档的后端仓库，不是当前前端仓库。

## 前端行为

- GET /api/v1/studio/scripts/imports 的列表项接收可空的 coverFileId、coverUrl、coverType，旧接口未返回时继续显示现有占位内容。
- 项目大厅按 coverType 渲染图片或视频，复用现有媒体地址解析和卡片裁切样式。
- 视频使用原始 coverUrl，静音、行内播放，仅预加载元数据；鼠标移入播放，移出暂停，不抢占卡片点击进入项目的行为。
- 地址为空、类型未知或媒体加载失败时显示现有占位内容；媒体标识变化后重新尝试加载。
- 最新媒体的成功状态筛选、跨来源排序、鉴权和分页由后端负责，前端直接消费列表结果，不逐项目追加媒体查询。

## 联调验收

使用分别返回图片、视频、三个字段全 null 的项目检查卡片；另检查旧响应缺少字段、失效地址，以及失败后更换媒体能否恢复。视频封面应静音预览，卡片点击和键盘进入项目仍可用，关键词及分页正常。
